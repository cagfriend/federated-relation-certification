# 半分布式异构联邦聚类：关系认证与自适应传输

原始逐轮大JSON以无损ZIP保存，解压即可恢复原路径；汇总与代码直接可读。见[归档与恢复说明](archives/README.md)。

研究快照：2026-10-30。本文档对应当前方法与已保存的实验结果，仓库用于私有研究备份。

客户端通过公共无标签样本对的“是否同簇”硬关系交换知识。聚合者累加各客户端的判断，返回同簇比例供本地公共关系训练。模型参数不直接平均，因此客户端可以使用同模型家族的不同宽度或特征维度。

当前优化用保守候选簇集合认证样本对关系，仅对无法认证的必要端点重新计算教师预测；上传和下发都自适应选择完整向量、变化列表或无变化确认。当前已验证实现为冻结 MLP 编码器与可训练线性聚类头，不能把实验结论直接推广到持续更新的整个网络。

## 当前结果概览

B=全量教师计算，E=逐样本认证，D=关系认证；三者使用同一自适应传输编码。以下是同配置、同种子配对后取三个种子的中位数。

| 公共样本数 | D/B 关系生成耗时减少 | D/B 完整头部训练耗时减少 | D/E 完整头部训练耗时减少 |
|---:|---:|---:|---:|
| 4,096 | 68.50% | 5.81% | 1.29% |
| 8,192 | 72.96% | 9.50% | 0.93% |
| 16,384 | 66.01% | 11.39% | 1.36% |

此实验固定私有数据43,616张、公共候选池16,384张、六个客户端、10簇、degree=1图，运行200轮、三个种子，共27次方法训练。全部配置内B/E/D的逐轮参数摘要、通信记录及已记录评估一致。扩大公共库同时增加图边数和公共学生更新步数。

关系认证没有在共同编码基础上进一步压缩通信。它需要额外内存：最大规模下，六客户端合计的持久方法数组比B多25.35 MiB。上述训练耗时是冻结编码器后的头部训练流程，排除编码器准备、评估、oracle审计及真实网络等待。

## 新完成：连续缓存 E/D 路径选择（含负结果）

公共样本4096、degree=1/4/8、三个既有seed，各200轮；重新确定性执行E训练捕获教师快照，对比固定E、固定D、简单static与adaptive四套独立连续缓存。以下为同seed配对后中位数，关系生成时间包含首次全量初始化和策略开销。

|degree|固定D/E耗时比|adaptive/static耗时比|判断|
|---:|---:|---:|---|
|1|0.77871|1.17736|D有利；当前动态规则比静态慢17.74%|
|4|1.00229|0.99830|接近持平，未获稳定动态收益|
|8|1.10867|0.99571|D更慢；动态全程走E，微小领先不算选路收益|

## 新完成：非IID＋模型宽度异构

### 配置与结果

Fashion-MNIST，IID/容量约束Dirichlet α0.5/0.1，三个既有seed404/505/606；每划分独立私有无标签AE与KMeans后冻结编码器。六客户端宽度512×3/2048×3，私有共43616张、客户端容量几乎相等；公共候选池16384、实际4096、degree1、K10、头200轮。9组36条Local/B/E/D真实训练轨迹，另36次单方法内存回放。同seed三划分公共ID相同，实际私有ID/直方图从官方标签重建一致；强非IID客户端自然缺1–5类，未测试数量不均。

同seed先配对再取三seed中位数，下面是耗时减少百分比：

|划分|D/B生成减少|D/B头训练减少|D/B C0＋头减少|D/E头训练减少|
|---|---:|---:|---:|---:|
|IID|69.56%|5.77%|4.03%|1.04%|
|Dirichlet α0.5|66.91%|5.02%|3.60%|0.91%|
|Dirichlet α0.1|59.77%|4.92%|2.88%|1.31%|

D/B头训练9/9胜出；D/E生成约减少25%，头训练8/9胜出，α0.5一个seed略慢。头时间含初始化，排除oracle/评估；C0含AE、特征、KMeans，未按方法数摊薄。不是包含真实网络的部署耗时。

### 正确性、质量与限制

66355200次硬关系和88473600次候选检查零误差；同配置B/E/D逐轮参数摘要、消息字节与全部已记录评估一致，认证未额外降低聚类质量。协作B−Local平均ACC增益中位数在IID/α0.5/α0.1为0.030/0.080/0.317个百分点（分别3/3、3/3、2/3为正）；α0.1的NMI只有1/3为正，不能认定稳定全面的协作优势。

强非IID训练途中已记录B最低占7簇、最大簇比例65.87%，最终B/E/D所有客户端占10簇但仍可有大簇集中；不能泛称无坍缩风险。跨划分ACC降低在B/E/D中完全相同。D较B多约6.78 MiB持久方法数组，单方法进程峰值约多10.9%，与E持久数组相同。三方法通信相同，没有新增通信压缩。

60个正式产物、6个新实验源码、13个核心源码审核通过，五份汇总重生成逐字节一致。局限为固定编码器＋线性头、一个数据集和degree1、既有三个seed、固定leader0及全员在线；未接入恢复协议。共享C0给Local计入不必要的公共特征，不能用于宣称协作相对Local最低独立总成本更低。

## 新完成：跨客户端关系知识机制消融

9组/36条真实训练完成：Local无公共更新，Self使用自身硬关系，Aggregate等权计数/N含自身，Shuffled置换自身分支的聚合目标；后三者公共BCE预算相同。沿用Fashion-MNIST、三个既有seed、IID/容量约束Dirichlet α0.5/α0.1、六客户端异宽冻结MLP、M4096/degree1/K10/200轮。

|划分|Aggregate−Self ACC差|Aggregate−Shuffled ACC差|Aggregate−Local ACC差|
|---|---:|---:|---:|
|IID|+0.007个百分点|+0.017个百分点|+0.030个百分点|
|α0.5|+0.057个百分点|+0.050个百分点|+0.080个百分点|
|α0.1（主场景）|+0.833个百分点|−0.662个百分点|+0.317个百分点|

以上先逐seed配对再取中位数。主场景Aggregate胜Self的ACC在3/3 seed为正，但胜Shuffled为0/3；预定要求两比较均3/3为正且中位差≥0.5个百分点，故**主筛查未通过**。Self−Local ACC中位−0.517个百分点，Shuffled−Local+0.678个百分点；Aggregate相对Shuffled的NMI中位+0.01110、ARI+0.00353，指标方向不同。不能认定正确对应的跨客户端关系带来稳定全面质量提升，也不将打乱目标宣称为普遍更优方法。

每分支依赖自身轨迹，Shuffled保留的是自身当轮原聚合向量的值分布，不保证与Aggregate整个训练分支始终同分布；同anchor梯度probe才严格同快照反事实。因此最终对照未单独识别所有机制。梯度与离线关系真值诊断有相关线索，但不提供因果解释。

26文件哈希、5400目标日志精确重建、7128梯度探针覆盖与3600历史Local/B轮方法对照通过，7份报表重生成逐字节一致。66355200为已处理教师关系条目数，不是独立样本数或新的认证压力测试。本轮不作D/E性能确认或新增通信压缩声明。

本轮新增round1检查，强非IID每个seed/分支都至少有一个单簇/100%集中的客户端（Local也有）；最终全部客户端恢复/保持十簇，但仍存在大簇集中。旧历史评估从round20起，不能将新增观察窗口称为新回归，也不能据最终十簇宣称全程无坍缩。

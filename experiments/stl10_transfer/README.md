# STL-10第二数据场景迁移实验

正式配置在[运行前协议](PREREGISTRATION.md)。只改变数据准备接口；原有私有头训练、固定公共BCE、关系认证、聚合和编码协议继续复用，不修改此前实验源码。

## 本轮回答的问题

在彩色自然图像、较小私有数据和有分布差异的公共参考库下，D是否仍比B/E节省完整流程计算？公共M扩大时，在固定学生更新预算下，生成占比和整体收益怎样变化？

36次正式方法运行：3seed × IID/强非IID × M4096/16384 × B/E/D。每次独立进程、CPU头部单线程、串行；私有AE准备可用CUDA。只有一轮技术重复，属于探索性第二场景迁移，不机械复用此前C1/C2/C3确认。

## 结果解读

主看D/B、D/E完整头和C0+头部配对比、绝对省秒与seed方向；生成阶段、重算比例解释原因。通信同协议，不能把相同编码的字节差误称新增通信压缩。持久数组与含审计的进程峰值分别解释。

同配置B/E/D必须逐轮等价、零错误认证；跨M的ACC/NMI/ARI、最差客户端及簇占用用于描述使用边界。固定≤1个百分点平均ACC容忍仅用于跨M敏感性，质量提高不作为继续条件。只看到认证快而完整流程未省时，按边界报告。

数据来源、输入处理、所有额外准备和缓存成本如实计入。没有借助测试集挑编码器、簇数或损失权重；不将外部分布的无标签公共集描述为保证同类覆盖。

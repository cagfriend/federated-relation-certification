# STL-10 编码器集中诊断

逐批重放已有 STL-10 小规模实验的本地自编码器预训练。先用 IID 划分的 client1 与 client4，两端各有 200 个私有样本。记录随机初始化和之后每个 minibatch 更新后的快照。数据、宽度、初始化种子、批次顺序和优化器与历史准备阶段配对。重放的最终模型必须与缓存逐字节一致，否则停止出报告。

每个快照只读同一批公共图像，用同一组私有图像拟合 KMeans，并按原方法构造中心头。观测 ReLU 后归一化前后的第一主成分占比、有效维度和绝对离散程度，同时记录通道激活、私有与公共簇大小、固定公共图上的同簇边比例，以及同一簇分布下随机取两个不同样本的同簇概率。聚类与观测均不参与参数更新。默认用公共集诊断，`--score-test` 可以额外输出原生头的留出 ACC/NMI/ARI，用于回顾性评估。

在原工作区运行：

```powershell
D:\anaconda\python.exe -B -m experiments.encoder_collapse_probe.run --preset pilot
```

需要同时复核强非 IID 时，加 `--partition iid dirichlet_0.1`，如果已跑过默认输出，再用 `--output` 指定一个新目录。默认输入是 `experiments/external_pilot/results_pilot_observed/cache`。输出包括 `report.md`、`steps.csv` 和保留每个通道及簇的 `results.json`。用 `--preset smoke` 可调用原缓存生成流程临时构造合成输入。

先比较第 0 步和各训练批次。如果第 0 步已经集中，下一轮交叉宽度与初始化种子。如果在某个重建更新后突变，优先将该步前后的快照做配对，并把较早快照作为低成本修复候选。client1 和 client4 同时在宽度与初始化上不同，本轮轨迹只能定位变化发生的时点。绝对离散程度和同簇边同时判读，以免把单方向方差高直接等同于所有样本相同。若提前停止有希望，再用现有私有校正及 0.5 保护做短程配对。候选依据公共诊断预先选定，留出评分用于验证。

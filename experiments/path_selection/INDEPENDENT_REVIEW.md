## 主要审阅问题与处理

1. **历史结果没有教师权重快照。** 实现确定性重跑一次 E 训练，捕获 private SGD 后、public SGD 前快照；逐轮检查 public 后摘要与通信，评估对齐历史。文档明确重新训练一次，不宣称直接从旧 JSON 还原权重。
2. **初始化不应作为普通上轮重算率。** `last_fraction=None`，首个 post-bootstrap 调用使用静态规则；之后只使用本策略上轮真正执行 generate 的重算率。全量初始化时间仍计入总成本。
3. **禁止拼接 E/D 独立缓存。** 每个策略/客户端仅构造一次 PolicyGenerator，切换只改变 mode；压力测试与手动指定相同模式序列的独立参考逐数组摘要一致。
4. **禁止同轮双路试算。** 决策先于本轮认证，只读模型宽度、图度和本策略上轮统计；测试断言每轮只调用一次选择器。其他策略的结果仅用于离线对照，不进入选择器。
5. **保存摘要的证据边界。** JSON 保存逐轮训练/目标/缓存摘要和统计，完整缓存与权重未落盘。全量 oracle 核对是绑定源码的运行时断言，不能单凭 JSON 重建数组独立证明。

## 非阻断建议

可增加初始头摘要与历史 `initial_head_digest` 的显式核对。现有每轮 post-public 摘要、消息和评估均与历史一致，不阻塞当前验收，当前交付未增加这一可选检查。

## 性能结论限制

只有小配置正确性结果与正式预检，未运行完整性能实验。动态阈值为冻结的探索启发式，必须与简单静态选择比较；是否值得继续由正式结果决定。当前未验证新种子、整体训练加速、额外通信节省、更新 encoder、非 IID、真实网络或临时聚合者换届。

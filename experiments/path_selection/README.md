# E/D 路径选择：连续缓存与低成本决策

这是下一步的**探索实验**，目的不是预先证明动态策略优于固定 E/D，而是检查选择与切换的成本能否被节省的教师重算覆盖，尤其能否优于简单静态选择。原认证、训练损失和消息协议未修改。

## 比较什么

|策略|每轮选择|
|---|---|
|E|总用逐样本认证|
|D|总用关系认证|
|static|图度为 1 用 D；图度为 4/8 用 E|
|adaptive|依据本客户端模型宽度、图度、本策略上一轮实际重算比例选一路|

动态规则在运行前写入 `selection.RULE`，不读取本轮候选矩阵、当前耗时或其他策略结果：

- 首次初始化后沿用静态选择，初始化的全量前向不作为上轮重算比例。
- 之后若“上轮重算比例 × 图度 ≤ 0.15 × 模型宽度 / 2048”，使用 D，否则使用 E。
- 这是便宜的保守启发式：图更密倾向 E，矩阵乘更贵的宽模型更容许 D。0.15 和宽度缩放**没有实验证明最优**，不应根据本次结果来回调参后宣称独立确认。

每个客户端、每个策略只有一个 `PolicyGenerator`。切换仅修改认证分支，不清空累计变化界，不重置参考、不迁入固定 E/D 的缓存。决策只用本策略过去已完成的统计；本轮只执行一路认证。强制交替和连续多轮切换另在单元测试中验证，不算作性能策略。

## 配置与执行

复用上一轮完整图密度结果中的配置及已验证特征：Fashion-MNIST，IID 私有划分，公共样本 4096，图度 1/4/8，模型宽度 512×3 / 2048×3，10 类，200 轮，seed 404/505/606。共 9 组配置-seed，每组 4 个独立缓存策略。CPU float64 单 BLAS 线程。

旧 JSON 没有保存教师权重。程序**重新确定性运行一次真实 E 训练**，捕获每轮私有 SGD 后、公共 SGD 前的教师快照；逐轮检查公共训练后头参数摘要、消息字节、最终评估与历史 E 一致，然后在这些教师快照上比较各策略。各策略各有独立协议状态，关系、解码、计数和接收目标与全量 oracle/E 核对。

## 重点看什么

1. **正确性必须零误差**：关系、候选包含真实赢家、提交/接收计数、消息字节、历史训练摘要与评估。
2. **主指标：含首轮全量初始化的关系生成耗时**。快照复制、缓存创建、决策、切换和策略统计写入均在计时内。每客户端 `decision_seconds` 仅测选择判断主体，已经包含在总生成时间中，不能再次相加。历史训练、oracle、摘要和评估在该计时外。
3. 次指标：去初始化的生成耗时；生成＋消息交换＋协议 setup 的累计耗时；教师重算比例；E/D 被选次数；切换次数；持久数组字节。协议 setup 单列且只在“生成＋交换＋setup”汇总中相加一次。不是进程峰值内存测量，未计 Python 对象占用和真实网络。
4. **必须与 static 对照**，不仅与 D 对照。静态与固定方法走同样轻量 wrapper，决策时间均计入；若路径相同，它们的缓存摘要应完全一致，耗时差反映测量噪声和轻微 wrapper 差异。

执行顺序按 seed/轮次/客户端轮换，降低固定先后顺序偏差；不使用同轮测得的 E/D 时间作选择输入。

## 结论边界

这是同教师轨迹的关系生成/协议开销实验，不是四套完整训练的端到端测速，不报告新的整体训练提速。消息编码相同且消息必须相同，没有新增通信压缩。当前还是冻结特征、线性头的认证，未拓展到更新 encoder 或非 IID。

当前种子曾用于诊断，这轮只作探索。若动态选择优于静态且跨种子稳定，再冻结规则并准备新种子确认；若不优于静态，就保留简单适用区间，不增加复杂预测器。是否自适应有用由结果决定。

保存的摘要能核对训练/目标/缓存状态的一致性，但没有落盘完整权重和缓存数组；全量 oracle 比较是哈希绑定代码中的运行时断言，不能从 JSON 单独重新构造证明。数值 guard 仍是实用浮点保护，不是形式化浮点证书。

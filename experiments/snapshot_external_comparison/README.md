# STL-10 最新快照版、外部对照与间隔保护开销

| 配置 | 用途 |
|---|---|
| seed 1201，IID / Dirichlet α=0.1 | 对齐上一轮外部比较的两个配置 |
| seed 1207，Dirichlet α=0.1 | 已知有客户端无法从最终快照初始化 |
| seed 1208，IID | 已知能启动但存在严重持续集中 |

每个配置 200 轮，6 客户端，私有 1200 张、公共 512 张、测试 1000 张，保持既有宽度和训练预算。四个配置共 28 次独立进程运行。每配置 Hetero-SSFL、FLESD、FedMKD 各一次，Ours 的间隔保护权重 0 和 0.5 各两次技术重复，配对顺序相反。配置中包含已知失败案例，因此汇总按配置报告。

最新版采用中心初始化、全客户端私有频数校正和按客户端筛查回退。各方法从同一份原始 AE 缓存开始，Ours 把筛查和回退计入方法准备，外部适配方法从终点继续各自的编码器训练。筛查评估私有伪簇和同一公共无标签集。最终快照缺簇或私有、公共最大簇任一超过 50% 时回查，从合格候选选公共同簇概率最低的一步。候选并列取较晚一步，只有集中候选时记录风险。两个 Ours 分支校验选定编码器、中心和起始评分一致。

主质量表用原比较的统一 KMeans 评分流程，聚类器在各客户端私有表示上拟合，在共同留出测试集评分。外部方法输入编码特征，Ours 输入头部概率。记录逐客户端 ACC/NMI/ARI、任取两张不同测试图像被判为同簇的概率、簇大小、空簇、平均及最坏最大簇。Ours 同时报告原生头聚类和教师同簇边率。后者来自硬关系训练协议，仅对 Ours 有定义。测试每 10 轮记录一次，标签只用于数据划分和留出评分。

耗时包括方法初始化和客户端、协调者训练，另列 AE 与快照筛查成本。评估、审计、进程启动和磁盘加载在计时之外。报告计算、序列化和聚合拆分，以及实际协议上下行字节。外部耗时比较的是这些适配实现的整体工作量。约束直接开销使用私有梯度路径中的内置计时，覆盖间隔项与梯度合并。训练净变化使用同配置的完整训练配对差，包含后续教师和公共训练轨迹变化。快照时间按当前有条件重放实现记录。两次技术重复用于了解计时波动。

在工作区根目录运行。

```powershell
D:\anaconda\python.exe -B -m experiments.snapshot_external_comparison.run --preset full --output experiments/snapshot_external_comparison/local_replays/full
```

克隆后通过 `--output` 指定新的输出目录，例如 `--output experiments/snapshot_external_comparison/local_replays/full`。中断后在同一命令加 `--resume`。已封存的方法运行保留，未封存的整次重跑。正式计时建议插电并保持电源模式稳定。默认读本地 STL-10 原始二进制，首次生成新的实验缓存。也可通过 `--data-dir` 指定已有数据，或用 `--preset smoke` 验证入口。

已归档的 [results_full](results_full/report.md) 包含运行汇总、逐检查点评估、保护配对和逐轮 JSON。归档保留每次运行的原始字节与校验回执。公开清单将本地数据路径替换为仓库相对路径，并记录原清单 SHA-256，便于与运行回执关联。公开归档用于审阅，复现会生成新清单与缓存。[审阅结论](../../docs/evidence/SNAPSHOT_EXTERNAL_COMPARISON_20261118.md)

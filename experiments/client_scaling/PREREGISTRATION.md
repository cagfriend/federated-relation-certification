# 客户端数 N 扩展实验

日期：2026-11-04。运行前固定；本次仅交付代码，正式运行由用户启动。

## 问题和矩阵

研究同一方法在不同客户端数下的计算、通信及空间成本边界。精确认证必须保持同配置 B/E/D 的关系、聚合目标、参数轨迹及评估相同；不要求 ACC 提高。不同 N 的划分、表示和学习轨迹改变，跨 N 差异不是仅改变聚合复杂度的纯因果估计。

|项目|正式设置|
|---|---|
|客户端数|2、6、12|
|默认分支 fixed_total|总私有样本固定 5000，每客户端尽可能等量|
|独立分支 fixed_per_client|每客户端恰好 400 张，总量 800/2400/4800|
|数据|官方 STL-10；私有来自 train，公共来自 unlabeled，test 仅评估|
|模型|同一 MLP-AE 家族，一半宽度 512，一半 2048；各客户端独立准备并冻结表示|
|其余|K=10，公共 M=16384、degree=1，每客户端每轮公共 2 步、batch256；完整私有 epoch、batch128；200轮；每20轮评估|
|划分与种子|IID / Dirichlet α=0.1；1001、1002、1003|
|方法|B/E/D，每配置各一次，独立进程、串行单线程；三元组内轮转顺序|

每分支 18 个配置、54 次方法运行。`--regime all` 共 108 次，不合并两个分支的统计。`--memory-audit` 每分支增加 12 次独立进程回放：seed1002 × N2/N12 × 两划分 × B/E/D。默认推荐先运行 fixed_total。

固定每客户端量受 STL-10 私有池 5000 张限制，不能保持历史约833张并增长到12客户端。因此该分支固定400，不复制客户端或样本；不使用 test 训练。沿用既有准备函数：取官方训练文件前 total 张，再进行同一 IID/Dirichlet 划分。跨客户端私有 ID 不重叠，覆盖选定前缀；前缀嵌套不代表客户端身份/分配或其表示跨 N 保持不变。分布与类别覆盖写入各缓存 partition.json。

公共抽样随机流不变；同 seed 下各 N/分支公共 ID 和顺序一致。图由原引擎生成，各配置三元组必须图摘要相同。每客户端公共预算固定，因此系统公共更新总步数随 N 增长，这是部署工作量的一部分，不能全归于聚合或认证维护。

## 准备与历史锚点

调用原 `stl10_transfer.data.prepare/verify`，不修改原 AE、KMeans、划分、学生、认证或协议实现。每个新划分独立训练 AE 并生成私有伪标签。fixed_total/N6 复用已有六份缓存，并核对六份历史 `stl10_compute` B 轨迹；旧计时不混入新计时。正式默认 CUDA 准备；锚点要求与原准备配置一致，不能以 CPU 重备冒充原锚点。

记录原始共享准备成本、各次缓存加载、头部计时；复用缓存的历史准备成本不记零。新的 N 需重备，其准备成本单列。准备时间可能包含输入验证/I/O；不是纯 AE 时间。检查正式源文件、缓存文件和运行源码摘要。保持全部历史代码和结果不变。

## 主要比较和解释

同 regime/N/划分/seed 内计算 D/B、D/E：完整头部耗时比、绝对省秒、生成阶段比、含准备与加载比。按 seed 配对后分别报告中位数、范围和胜出数；不把200轮当独立实验样本。每方法一次，这是规模边界探索，不是新增重复性能确认。

分列私有、生成、exchange、公共耗时，以及教师前向端点、认证率、持久数组、序列化通信字节、独立进程峰值。exchange 是串行内存协议的序列化/聚合/交付处理，不是真实网络时延。每客户端均摊耗时只作算术描述，不是最慢客户端耗时或并行关键路径。完整头部口径不含 oracle、评估和模型准备；另列准备加加载加头部口径，完整进程墙钟不等于算法耗时。

内存回放关闭 oracle、coverage 和评估；保持训练不变，方法专属非计时逐轮字段也必须与对应审计运行一致。峰值包含解释器及输入校验/加载；只覆盖两个 N 端点、一个种子，不能外推全部 N/种子，不是显存。

## 正确性和质量边界

全部正式三元组逐轮检查关系 oracle、候选成员、提交计数、学生目标、私有和公共更新、头摘要、损失和最终评估；B无候选集合，不计候选审计数。任一错误停止，不产出成功结论。

质量是边界记录：逐客户端 ACC/NMI/ARI、占用簇数、最大簇占比；每个检查点单簇或最大簇≥99%的事件单列；最终存在该类客户端时自动标记严重退化风险。报告保留对应开销数据并明确标识，不能据此声称在全部客户端可用的聚类任务上成功扩展。固定总量下每客户端数据减少可能改变质量，不把它归于认证；不按质量结果事后筛选 N/seed。跨 N 无 ACC 正收益门槛，也不把新的 N 配置宣称与 N6 质量等价。

## 电源、中断和恢复

新运行、恢复及每个方法进程开始检查插电。父进程从准备阶段起每15秒记录时间与 AC 状态，记录缺口仅提示排查，不能直接视作休眠时长或扣除秒数；日志不等于全程硬件频率/温度监测。保留全部原始记录，不自动清除计时离群值。用户确认的中断另作明确派生分析，采用可比配置的共同掩码，不填补估计时间。

先写冻结环境，再增量保存已完成准备标记。`--resume` 校验版本、环境、缓存与完成记录，保留完整单次运行，未完成方法整次重跑。若中断发生在缓存准备中，原准备器会拒绝该未完成目录；检查报错路径后将该目录移出 cache 再续跑，不能删除已有完整缓存。手动暂停不是系统故障。

smoke 使用合成 STL 二进制格式、N2/4、总量256或每客户端32、M128、宽32/64、3轮、一seed、两划分。仅检查实现，不提供有效聚类、正式耗时或规模证据。

# 不同运行环境下的补充结果

本目录保留系统默认 Python 3.13.3、NumPy 2.3.5、OpenBLAS 0.3.30 下完成的 20 个配对性能配置和已完成的 17 个内存档案。

发现该环境与此前探索的 Anaconda Python 3.12.7、NumPy 1.26.4、MKL 2023.1 不同后，停止了余下内存任务；已有文件不覆盖、不删除。这里的 B/E/D 组内配对有效，但不能作为“只改变种子、其他环境不变”的主复核。

预先确定的四档幅度和五个种子保持不变，另在 `../results_sweep_holdout_original_env/` 使用原环境完整执行 20 个配对配置与 60 个内存回放。正式报告以原环境复核为准，本目录仅保留为运行环境不同的补充证据。没有依据此处结果调整档位或方法。

# 固定档位、新种子的独立开销复核

日期：2026-10-29。

本轮执行在此前探索后预先确定的四档更新幅度与五个新种子，验证关系认证的计算收益能否跨种子复现，并补测内存。没有更换档位、排除种子或调整核心实现；本轮保护的 232 个已有文件逐文件 SHA256 未变。

正式结果使用与此前探索相同的 Anaconda Python 3.12.7、NumPy 1.26.4、MKL 2023.1，CPU 单线程。最初系统默认解释器已切换为 Python 3.13.3/NumPy 2.3.5/OpenBLAS，主 AI 在环境复核时发现后纠正，未以该批数据替代同环境复核。该批 20 个性能配置和 17 个已完成内存档案保留为补充数据；之后在原环境重新完整执行同一冻结计划。没有依据补充结果改变种子、档位、顺序或方法。

## 冻结设计

- scale：0.05、0.10、0.12、0.16；种子：404、505、606、707、808，与探索种子不重叠。
- 其余保持默认：4096 公共样本，K=8，6 客户端维度 512/512/512/2048/2048/2048，2048 条匹配边，每个样本恰好出现一次，200 轮加初始化，float64，CPU 单线程 BLAS。
- B：全量前向＋自适应全量/差分；E：逐样本认证＋同一编码；D：关系认证＋同一编码。每个配置三组在同一进程内共用输入、参数轨迹与协议，独立缓存，每轮轮换顺序。
- 总计 20 个配对配置、60 次方法运行、12,060 条逐轮记录；另做 60 个隔离进程完整内存回放，测量内存时的耗时不混入性能数据。
- 执行顺序按种子分块、块内随机排列四档。使用原 CLI 逐配置执行；内存回放在全部计时完成后串行执行，逐项保存。
- 运行前冻结 plan.json 和 execution.json。每档逐种子先求 D/B、D/E，再报告中位数、最小/最大和胜出数。5/5 为全部新种子复现，4/5 为多数但存在例外，至多 3/5 为跨种子不稳定；完整保留 0.16 区间外对照。

### 冻结问题的答案

前三档各自同时优于 B/E 的新种子数：0.05 为 5/5；0.10 为 5/5；0.12 为 5/5。
预先设为区间外对照的 0.16，本轮 D 对 B 胜出 4/5，中位成本比 0.994007，范围 [0.930549, 1.006924]。此前探索的 0.16 三种子均比 B 慢，本轮并未完全复现这一点；不能继续把 0.12–0.16 当作已确认的稳定过渡区。
胜出数只计算未四舍五入的比值是否小于 1；贴近 1 的微小差异不构成稳健收益余量。应同时看中位数、最差种子和后续实际训练中的表现。

负节省表示增加耗时。这里没有进行正式显著性检验；五个新种子支持的是该固定配置下的复核，不是普适性能保证。原始五对比值逐一列于文末和 paired_results.csv。

## 通信、正确性与审计

- 148,193,280 次硬关系比较、197,591,040 次候选成员检查，零不一致。
- 全部配置的 B/E/D 每轮消息字节与编码轨迹一致，关系、计数均经计时外全量 oracle 检查。因此 D 相对 B/E 的本轮新增收益是计算，没有额外通信压缩收益。
- 20 个配置均为完整 0..200 轮；逐轮耗时和流量重加总与汇总一致；配对统计重新从原始结果计算；60 个内存档案无缺项。
- 同种子四档初始头摘要一致；核心源码哈希、执行器和环境包装器哈希与冻结记录一致；Python、NumPy 和 BLAS 实现/版本/线程数与探索一致；232 个已有文件哈希一致。
- 原浮点 guard 沿用此前实现；零错误描述这些已运行轨迹的一致性，不代替完整浮点舍入证明。

## 解释范围

这是固定特征、线性聚类头、合成参数漂移的受控开销实验，没有私有训练、公共蒸馏反向传播、真实网络或聚类质量评价。公共输入预置，首次特征提取不计入。六个客户端在单进程中串行模拟，累计阶段时间不是并行客户端的实际轮时。scale 是扰动控制量，不是实际学习率。不能将这些时间节省直接写成端到端 FL 加速，也不能从四个离散点推出精确连续阈值。

这轮保留既定档位并换新种子复核，能够支持或否定此前区间的可复现性。后续若进入真实训练，应保留 B/E/D 相同轨迹对照，另测完整训练成本和聚类指标；本轮不自动启动该阶段。

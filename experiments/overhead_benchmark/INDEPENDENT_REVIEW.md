# 独立复审：受控开销实验

**结论：有条件通过。** 本轮未发现会阻止该受控实验按约定运行的实现缺陷。A/B/C/D 的计算和通信隔离、硬关系正确性与提交参照在所检查的实现路径上符合约定；完整默认性能基准未运行。条件是：浮点候选证书只给出实数运算下的上界，并使用 `1e-10` 实用 guard；它不是对所有 IEEE 浮点输入的形式证明。实验 README 已明确披露这一限制，配置内逐轮全量 oracle 会发现所运行轨迹中的错误，但不能把该覆盖外推到所有输入。

## 缺陷与条件

- **中等、非阻塞：浮点认证不是全输入形式证明。** `certification.py:84-90` 的 L2 范数、前缀累加及 gap/bound 浮点运算使用 `1e-10` guard；极端尺度/舍入误差下，guard 不构成 IEEE 误差上界。README `:88` 已准确说明，配置运行逐轮 oracle 会拒绝观察到的错误而不会修补缓存。因此本结论只覆盖已验证的数值轨迹，不应宣传为对任意浮点快照无条件严格认证。没有要求修复，因为本实验已声明边界且在用户要求配置下有独立 oracle。
- **低、非阻塞：协议验证不是网络协议/共识验证。** 当前为 leader=0、term=1、全成员在线的同步内存状态机，未覆盖丢包、重传、leader 变更、并发部分提交恢复。`protocol.py:1-6` 和 README `:77` 已披露；与本次仅回放非训练开销的范围相符。
- **范围限制：未测真实训练、真实链路与完整默认性能。** 固定合成特征和人为参数更新，不执行 K-means、私有训练或蒸馏；消息 bytes 是应用层 bytes；没有跑完整性能/内存基准。这些都在 README `:3, :63, :72-86` 明示，故结果只能支持受控机制/开销回放，不能表述为端到端联邦训练加速。

**主代理可继续执行完整性能基准。** 在当前报告范围内，A/B/C/D 设计和实现可验收为“有条件通过”；后续对外结论应保留上述浮点和模拟环境边界。

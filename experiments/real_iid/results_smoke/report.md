# 真实数据 IID 实验结果

已完成 1 个配对种子。数据：Fashion-MNIST。

CPU float64 线性头执行真实私有 CE 与公共关系 BCE SGD，编码器冻结。六客户端串行模拟；消息在内存中真实编解码。本实验不测实际链路时延、分布式选举、故障恢复或能耗。

## 检查与诊断

- oracle 关系比较：576；候选成员检查：768；零不一致。
- B/E/D 每轮学生更新后头参数摘要、通信轨迹均要求相同；教师关系和接收计数由全量 oracle 检查。错误即停止，不静默修复。
- 聚类质量按每客户端分别计算，再取客户端平均；每客户端簇占用数、最大簇比例和完整分布见原始 metrics。
- B/Local 的 NMI 差：seed 101: -0.0113
- 若 B 未优于 Local，应先诊断协作学习目标和图信号；不得只凭节省计算宣称学习价值。
- 匹配图每点仅一条边。之后需另检验图密度及非 IID；本轮不外推这些场景。
- 浮点 guard 沿用既有原型，并逐轮核验；实测零错误不代替完整 IEEE 舍入证明。

# 跨客户端关系知识的机制消融

本轮验证其他客户端的关系信息是否有独立学习价值，不承担D/E性能确认任务。保留现有冻结编码器、私有伪标签CE与公共关系BCE，不改变损失、图、模型规模或聚合权重。

## 正式设计

Fashion-MNIST训练60000、共同测试10000；IID、容量约束Dirichlet α0.5/α0.1，三个既有seed404/505/606，共9组配置、36条实际头部训练轨迹。各划分独立私有无标签AE预训练5epoch及一次KMeans后冻结；宽度512×3/2048×3，私有总43616张，每客户端约7269/7270张。公共候选池16384，实际公共4096、degree1共2048边、K10、头200轮。公共BCE每轮完整遍历，batch256、1epoch、weight1、学习率0.1；私有batch128、1epoch。

可复用上一轮通过校验的9个准备缓存，复用的是固定图像特征/私有伪标签，不复用训练后的头或本轮结果。缓存不存在时按原流程重新准备。当前三seed是机制探索，不能称为新seed独立确认。

|分支|本轮公共训练目标|教师生成|公共优化预算|
|---|---|---|---|
|Local|无|仅诊断检查点作额外只读前向|0步|
|Self|本客户端本轮教师的硬同簇关系|全量B|与下面两组相同|
|Aggregate|等权客户端硬关系计数/N，含自身贡献|全量B|固定完整图遍历|
|Shuffled|该分支本轮聚合目标在边之间置换|全量B|固定完整图遍历|

所有分支从相同初始头开始、使用相同私有数据/顺序与更新规则。Self/Aggregate/Shuffled公共批次顺序、步数、学习率、BCE权重、学生前向预算相同，唯一学习改动是目标。不同目标会令模型轨迹分叉；不强制保持更新后的参数相同。每分支按自己的当前模型产生关系，不让Self或Shuffled消费Aggregate训练轨迹的关系。

Self训练只消费自身关系，无跨客户端通信。为输出统一的离线诊断，运行器可在只读阶段计算其他客户端关系；这些聚合/打乱反事实只进入诊断，不用于Self的SGD。Local也不消费公共目标。

Shuffled复用现有可靠内存协议接收原计数，再按公共、预先固定的置换日程在每个学生本地重排目标；所有学生使用同一置换，目标值直方图精确保留。置换seed命名空间为`[seed,906,round]`，索引恒等时作一次循环移动；相同目标值很多时仍可能几乎没有实际改变，必须查看`shuffled_changed_edge_fraction`。这只是机制负对照的实现，不是新通信协议。各分支轨迹不同，消息字节不要求一致。

## 每轮顺序

1. 每个分支按原私有CE执行SGD。
2. 三个公共分支冻结本轮教师快照，全量计算各自公共样本与图边硬关系。
3. Self使用自己的硬关系；Aggregate使用精确计数/N；Shuffled在接收计数后置换。聚合协议仍核对每客户端关系、解码计数与接收目标。
4. 三分支执行完全相同预算的公共BCE。所有学生前向读取当前学生参数，教师快照不随公共SGD变化。
5. 预定检查点完成只读梯度探针及公共真值诊断，记录评估。探针使用步骤2的post-private快照，因此虽可在公共SGD后执行，其比较参数仍为同一冻结快照，不使用更新后的头替代。

## 梯度与关系诊断

round1、每20轮及最终轮评估并探测，完整配置共11个检查点。每个anchor分支、每客户端，在同一w/b、同一个私有mini-batch及同一个公共边mini-batch上比较Self/Aggregate/Shuffled三种反事实目标。probe随机流独立于SGD：私有`[seed,901,client,round]`、公共边`[seed,902,round]`。

每行保留anchor、client、目标种类、快照和批次摘要，私有/公共loss、原始与乘权重后的梯度范数、范数比、梯度余弦/夹角、目标差异。零梯度时夹角和无定义范数比写null。正余弦表示两项梯度局部同向，不直接证明长期受益；梯度冲突也不是负迁移的充分条件。

全图目标日志保存逐客户端位打包关系、目标摘要/直方图、原始计数及置换摘要、目标对自身关系的分歧、其他客户端相反比例、两两关系分歧。官方公共样本标签仅离线计算真同类关系、Brier及正/负边分项、常量先验Brier和真同/异类目标均值差。负边可能占多数，不能只看总体Brier。标签不传入私有CE或公共BCE目标；测试标签只用于ACC/NMI/ARI。

原始输入关系可从target_records位串精确还原，重建本轮所有目标并校验摘要和直方图；日志不包含全部历轮模型权重，不能凭日志独立重算全部教师前向。源码指纹、运行时在线检查、历史B/Local逐轮对照和单测共同提供执行证据。数值证书不在本轮扩展。

## 预先确定的判定

主场景α0.1，主指标最终轮客户端平均ACC。筛查实用差阈值为0.005，即0.5个百分点；这是本轮研究取舍，不是统计定律。Aggregate−Self及Aggregate−Shuffled两个比较都须三个seed全正、各自中位差≥0.005，才标记“探索筛查门槛达到，仍需新seed确认”。这是比单看B−Local更严格的筛查，不代表已完成显著性或新seed确认；未达到也不能证明所有协作方法无效。

IID/α0.5为次要场景，不挑最好场景改主指标。报告每客户端及均值ACC/NMI/ARI、逐seed配对差、范围/中位数/正seed数、受益/受损比例（>0/<0与≥0.005）、最差客户端差和簇集中。客户端作为seed内配对，不能增加独立样本量。最差客户端差不一定来自同一客户端；完整曲线保留，不选最好轮次。

如果Self已带来同等收益，需把原B−Local提升解释为公共自训练等因素；若Aggregate不胜打乱目标，不能归因于具体边关系语义。如果目标近常量使打乱对照弱，须先报告这个限制。不能据梯度范数单独断言原因。

## 运行

在工作区根目录执行：

```powershell
cd C:\Users\tjp\Documents\Codex\2026-10-14\new-chat
D:\anaconda\python.exe -m unittest experiments.collaboration_mechanism.test_mechanism -v
D:\anaconda\python.exe -m experiments.collaboration_mechanism.run --preset full --prepare-device cuda --download
```

默认输出`experiments/collaboration_mechanism/results_full`。这条正式命令由用户运行；开发阶段只运行单测和官方缩小smoke。没有额外36次内存回放，本轮不测新的D/E性能收益。

中断后原命令加`--resume`。已经完成的case保留，未完成case从第一轮重做，不能从某中间模型继续训练。resume冻结配置、种子、源码、运行库、缓存与历史参考文件；不接受新参数悄悄覆盖。如果源码变化应使用新的输出目录。

默认自动查找`experiments/noniid_clustering/results_full`的9个历史case（smoke相应为results_smoke），校验Aggregate逐轮头/消息/评估与原B一致、Local与原Local一致；历史路径或配置不一致时停止。可用`--reference-results <路径>`显式指定完整九组历史参考；参考不存在时明确标记未核对历史，并仍执行单测及当前在线检查。跨机器用新输出/缓存，旧绝对路径不能直接续跑。

小规模路径验证：

```powershell

```

smoke是官方Fashion-MNIST：训练1024、测试128、公共池128/实际32、宽度32/64、AE1epoch、头3轮，9组36轨迹。只检验路径和对照实现，不解释质量/筛查门槛；正式实用阈值仅用于完整full设计。

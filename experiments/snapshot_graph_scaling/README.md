# E38 公共图规模对照：定位关系认证的净省时边界

目标：在相同规模的 B（全量）、E（逐样本认证）和 D（关系认证）得到相同训练轨迹时，比较 D 的关系生成净收益和完整头部净收益。上一轮 512 规模结果不作计时对照，本轮在相同条件下重测。

|公共样本 M|固定匹配图边数|每端每轮公共步数 × 边批量|
|---:|---:|---:|
|512|256|2 × 64|
|4096|2048|2 × 64|
|16384|8192|2 × 64|

沿用上轮四组 STL-10 配置（1201 IID、1201/1207 α=0.1、1208 IID），200 轮、六客户端、K=10、0.5 全程间隔保护、全客户端私有频数校正。固定 E38 已选定的编码器快照、中心初始化、私有样本、测试样本及更新规则。公共库按原 STL-10 无标签样本随机流扩成嵌套前缀，512 档按 ID 及像素对齐 E38。每档用现有规则独立构建匹配图，不要求边集合跨档嵌套。扩图会改变教师关系分布、聚合数据量、公共批次的采样池乃至参数轨迹；只比较每档内 B/E/D 的精确性。两步固定的是学生实际接受的关系数和梯度工作量；边顺序采样、全量目标转换、关系生成和聚合仍可能随规模增长，全部计入。

先做 36 条非计时审计（四配置 × 三规模 × 三方法）。每轮用完整前向核对硬关系、提交计数、学生实际关系目标及采样；再核对同档头参数、通信字节和评估。512 档额外逐轮比对 E38，三档还要求同一初始头。审计通过后才跑 108 次独立正式计时（每格每方法三次，各 200 轮），串行单线程。轮换规模顺序，每格三方法各占首位、中位和末位一次。正式计时关闭全量 oracle，计时后复核摘要。建议插电、固定电源模式，运行过程采样并显示异常和未知状态。

分别对 B、E 统计 D/B 和 D/E。每格内先平均三次计时；平均至少省 3% 且至少两个块内更快，标为达到门槛。生成与完整头部分别判读，列出全计和插电监测完整的首次达标档位；不插值、不把技术重复或四个旧配置当作新种子。含准备时间在完整头部之上加上上次封存的共同 AE/快照筛选成本，用于说明固定准备成本如何摊薄收益。大图读取及预先生成公共库不在训练计时内，公共特征提取、图注册和首轮缓存构建计入。记录通信上下行、缓存及进程峰值、逐客户端 ACC/NMI/ARI、最大簇及严重事件。

在工作区根目录执行（默认直接使用本机已有 E38 结果、上次计时选定快照和 STL-10 二进制）：

```powershell
D:\anaconda\python.exe -B -m experiments.snapshot_graph_scaling.run --preset full
```

中断加 `--resume`。想先完成审计，可加 `--stage audit`，之后用相同输入和目录运行 `--stage timing --resume`。默认输出写入 `results_full`，含 `report.md`、`crossover.csv`、`comparisons.csv`、逐块数据及封存的轨迹。可用 `--history`、`--timing-reference`、`--cache`、`--data-dir` 指定现存目录，`--output` 设置新输出；旧结果不覆盖。准备阶段需流式校验无标签二进制并在输出目录为三个 seed 分别写出约 192 MiB 的最大公共样本库。启动时可能先有一段数据读取及处理时间。

`--preset smoke` 用 32/64/128 个合成公共样本和两轮训练验证流程，单档公共步数受合成图边数限制；不会给出性能门槛结论。

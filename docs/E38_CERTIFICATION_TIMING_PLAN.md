# E38 协议下的关系认证净收益复测

2026-11-19 · 实验设计稿。实现前按本文固定矩阵与口径；正式计时前封存源码、依赖版本、输入摘要、执行顺序和判据。尚未运行，不改 E38 原始结果。

## 问题与比较对象

使用 E38 的快照筛选与学习设置，检验关系认证在完全相同的训练轨迹上，是否相对全量生成、逐样本认证节省完整头部时间，以及计入共同准备后还能省多少。外部方法不重跑，现有 E38 外部对照只说明整套实现的成本差异。

| 方法 | 每轮由教师生成关系的方式 |
|---|---|
| B | 全量计算公共样本标签，再生成约定图上的硬关系；不维护认证缓存 |
| E | 沿用现有逐样本认证；计算不能唯一确定标签的样本，再生成硬关系 |
| D | 沿用 E38 关系认证；直接认证可判定的边，只刷新剩余不确定边所需的端点 |

三组从本轮私有更新后的同一时点取教师参数。生成器之外共用一条训练路径，沿用自适应关系编码、聚合、两步公共更新和批次随机流，不引入额外的缓存共享、换图、学生前向复用或动态策略切换。三组均从冷缓存开始；首轮全量前向和 E/D 构建参考状态均计时。

## 阶段 A：先对齐，再开始正式计时

1. 按 E38 归档回执校验历史 `Ours-0.5` 两次运行及本地缓存；记录私有/公共/测试样本及顺序、快照选择结果和模型、中心、伪标签、初始头与图的摘要。若原缓存缺失，按原规则重建并验明身份；若选出的快照或轨迹无法匹配，停止并排查，不能替换样本或放宽标准。
2. 四配置每个做一套 B/E/D 的 **200 轮非计时回放**，共 12 条。用同轮 B 的完整 hard relation 向量作为精确参考，按客户端比较 E/D；检查聚合计数和各端实际消费目标、私有/公共批次索引、各端头参数、实际分轮上/下行字节和检查点评估。认证生成器的端点数量是方法差异，不要求一致。
3. D 另与 E38 的两份历史 `Ours-0.5` 对齐：快照选择和初始化中心、200 轮头摘要、既有关系/聚合比例、分轮通信和 21 个评估点的可比较字段。E38 仅保存了教师和聚合比例等摘要，不能用比例相同冒充边级历史回读。边级和目标级精确性由本轮完整 B 参考保证；新回放封存逐轮摘要，供计时阶段复核。
4. 任一关系、提交目标、头参数、分轮协议字节或质量记录出现无法解释的差异，先查实现或环境，不能用这条轨迹得出认证省时结论。

## 阶段 B：36 次独立进程正式计时

四配置 × 三方法 × 三次技术重复。串行 CPU、固定线程数为 1（含 BLAS 和 PyTorch），同一机器、插电、固定电源模式。每配置以“三方法连续跑完”为一个计时块：配置 1/3 使用 `B-E-D / E-D-B / D-B-E`，配置 2/4 使用 `D-E-B / B-D-E / E-B-D`。每个方法在每配置各占一次首位、中位和末位，六种次序各用两次。每次从同样的输入和空认证缓存开始；只做相同的进程级运行库热身，不能提前生成本轮关系或预填缓存。

正式阶段关闭 oracle 与额外探针。关系、提交目标、头摘要和评估在计时窗口外复核，并与阶段 A 对齐。若记录摘要需拷贝，放在窗口外并统一三组的观测方式；主计时累加实际训练窗口，不能把质量评估、日志、审计、进程启动或磁盘载入混入。异步测量或准备阶段读盘等未计入的开销单列，不把单机串行时间称为网络部署轮时延。

## 指标与判读

| 口径 | 记录内容 |
|---|---|
| **主指标：完整头部时间** | 方法初始化 + 200 轮实际训练；含冻结特征提取、私有 KMeans/中心头、图注册、关系生成、序列化、聚合和学生更新。私有及公共阶段、首轮初始化和稳态生成另拆分。 |
| 含准备合计 | 同一配置本机测得的 AE 预训练和实际快照筛选/必要重放，各按一次共同成本，加到每方法完整头部时间。缓存复用用于保证同一起点；用同机独立准备复测且核对身份。若无法获得同机可核验准备时间，标为不可比，不拼接旧机器的秒数。 |
| 机制与内存 | 每轮全量/实际重算端点、认证边比例、首轮缓存开销、更新幅度、应用层上/下行字节；记录同口径进程峰值与认证持久数组字节。若系统进程峰值无法区分小规模差异，如实报告；持久数组字节不等于增量峰值。 |
| 质量护栏 | 每 10 轮逐端原生 ACC/NMI/ARI、最大簇、簇占用，及每轮教师同簇边率。单簇或 ≥99% 检查点逐条保留；跟踪反复单簇或持续集中伴质量下降，不以 ACC 提升判成功。 |

- 分别计算 D/B 和 D/E。每配置、每方法先平均三次技术重复，再取比值和绝对差（秒）；同时保留三个块内配对比值、范围和 D 更快的次数。建议预先采用 **3%** 作为完整头部时间的实际意义门槛：相对某基线，平均时间比 ≤0.97 **且**三个配对块中至少两个 D 更快，才标为该配置对该基线有清晰净省时。3% 是报告门槛，不是显著性检验。保留达不到门槛、速度反向或有较大波动的配置。生成和含准备的收益均按各自口径报告，不替代主指标。
- 四个既有配置含定向风险案例，并且 1201 重复用于两种划分。逐配置给结论，最多作描述性汇总；200 轮和三次技术重复不是新增独立种子。默认纳入所有通过完整性核验的运行。只有可证实的暂停、休眠或计时中断才作标记并重跑同一完整三元组；保留原始记录、原因和全计/有效分组说明，不按快慢剔除。封存已完成记录，未完成单方法进程重跑。
- 若 D 对 B 省时但对 E 仅小幅、反向或不稳定，写清认证相对全量、相对逐样本是两个结论。若仅关系生成阶段省时，说明 M=512 下未形成完整训练净收益，不追加档位挽救。本轮结束后，才另立更大公共图的优势边界实验：固定学生步数与边批量，使用新种子，保留 D 慢于 E 的案例。

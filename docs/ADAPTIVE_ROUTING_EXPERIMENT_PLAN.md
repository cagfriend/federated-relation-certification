# 精确关系生成：低成本选路实验设计

> 本文保留开发前设计。实际运行的 B/E/D/S/C、筛查结果和当前候选见 [E41 审阅](evidence/EXACT_ROUTING_BOUNDARY_20261120.md)。未来优先级以[待做实验](NEXT_EXPERIMENTS.md)为准。

状态：设计稿，未实现、未运行。当前研究问题是：**在场景变化时，客户端是否能用足够少的额外工作选到合适的精确生成路径，避开明显慢路？** B 全量生成、E 逐样本认证、D 关系认证都是可选路径。允许算法选择 B 或 E；D 的选择次数和每个配置 D/B、D/E 都省时均不是成功条件。

[最新实验](evidence/SNAPSHOT_CERTIFICATION_SCALING_20261119.md)显示，只看重算端点或公共样本数不能可靠决定谁快。早期[固定与动态选路](EXPERIMENTS.md)还显示，按上轮重算率切换 E/D 在稀疏图上比简单静态规则慢约 17.74%。这一负结果保留。新设计比较能否用更低的代价估计实际净时间。

E40 的归档只有教师快照摘要。重放须用原输入和冻结设置重新执行一次 B 轨迹并捕获真实快照，不能从摘要还原；开发轨迹与历史锚点对齐。留出场景的三档可以有不同训练轨迹，每一档内必须共用一条 B 教师轨迹。校准只能访问当时的前缀；测试标签、未来耗时和离线最快路径不得参与决策。

## 参照与两种候选

- **固定 B/E/D**：分别拥有独立的连续状态，呈现路径的资源代价。**简单静态表 S**：用开发数据按图规模与客户端宽度选 B/E/D，规则和默认回退 B 在留出前冻结。用 S 检验额外校准有没有价值。
- **候选 C：启动时短校准，之后固定。** 每客户端初始用 B，至多在前 8 轮附加试跑 E/D。同一客户端串行计时，只有 B 的关系参与训练；试跑路径各有独立缓存并按每轮连续推进。首轮初始化和所有试跑操作全部记账。前缀时间按轮配对，先从开发对照确定计时余量；预计剩余轮数省下的时间必须覆盖全部试跑账和后续建缓存成本，且优于 B 留有余量，才切换，否则保持 B。若保留相邻快照连续维护的所选缓存，可接着使用，记录内存；若已释放，则按当前全量打分重建。内存不足、预算不足、设备状态不稳定或证据不足时跳过试跑。记每端确实观察了多少轮，而非把最多 8 轮视为免费。
- **候选 P：低成本预测。** 只用已知的 M、K、宽度、图度数和过去观测等廉价量，在开发集拟合净耗时或时间比；在留出种子上先比较它和 S，再比较是否值得启用 C。先测一个简单查表/回归，不为提高预测分数再引入一次全图扫描。看错选的额外秒数，不以分类准确率作为主指标。
- **低频重选后移。** 只有在固定选路随训练阶段明显失效时再做。最短驻留期和滞回阈值事前冻结，每次只实际运行所选路径。E↔D 若共用一份合法、连续更新的缓存，可接着用；在 B 阶段若不维护认证状态，返回 E/D 必须用当前模型重新全量初始化，不能漏计快照变化或拿旧标签充当前关系。

## 判定与报告

1. **正确性前置。** 逐轮比对 B 全量硬关系、聚合计数与实际学生目标；完整训练再核对头参数、原生质量及实际通信字节。此前仅证明给定矩阵内零误差，不扩展为任意浮点输入的证明。路由留在本地，不增加协议消息；保持原训练、图和编码。共簇继续逐客户端监测，不要求 ACC 提升。
2. **首要指标是选路的净代价。** 总关系生成时间包括试跑、选路、缓存建立/持续维护/释放后重建和回退，另外记完整头部时间、内存峰值和最长客户端生成时间（作为串行数据上的关键路径估计，不当作部署延迟）。报告相对事后最快可用固定路径的额外秒数和比例（每个客户端在整个会话内选一个固定路径，独立连续回放；不拼接无切换成本的逐轮最小值）。同时报告相对 S 和 B 的最差退化、错误选择数与容易省时的场景中保留的收益。离线参照不向路由提供信息。
3. **事前门槛（设计候选，开跑前冻结）。** 留出矩阵上，自动策略相对 S 的中位额外成本更低（两者使用同一个固定路径参照）；每个小图格相对 B 的平均生成退化不超过 3%，内存不越预算；允许个别格选择固定 B。若 C 未优于 S/P 或短试跑开销吞掉净收益，优先报告简单静态策略及失败范围。按格显示负收益，技术重复先在格内平均，不能把轮或客户端当独立种子。
4. **计时异常与后续。** 串行独立进程、同一设备和电源模式，记录每段耗时与运行状态。明确休眠或中断复跑整个配对块，保留原值和原因；来源不明的慢轮保留，只提供敏感性结果。若留出验证通过，再考察跨设备和图度数迁移；若失效，优先分解候选矩阵、边扫描、端点刷新和缓存流量，再决定是否做动态重选。暂不扩更大图、500 轮或训练目标。

冻结时另列最短校准窗口、首轮与稳态拆分、内存上限、时间余量以及跳过试跑的条件。早期参数变化可能比后期更大：对开发轨迹分窗口报告前缀估计与后续的偏差；不能用后续耗时修正已经发生的选择。只在候选判断不明且剩余预算足够时试跑，报告小图跳过率与漏掉可省时路径的代价。

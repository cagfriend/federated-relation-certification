# 主张、依据与不能外推的内容

|主张|理论或代码依据|实验依据|允许结论与限制|
|---|---|---|---|
|硬关系绕开簇编号对齐|相等关系在同一客户端标签置换下不变；[学习协议](../method/learning_protocol.md)|异宽MLP真实训练|无需参数/编号对齐；不证明公共知识一定有益|
|候选集包含真实赢家|Cauchy–Schwarz+累计变化上界；[推导](../method/relation_certification.md)|E01/E02/E08及后续零错误核验|实数机制正确；浮点有限测试非全输入证明|
|标签不确定仍可认证关系|不交候选集与同单例规则|B/E/D、必要端点和候选核验|同图同轨迹精确保持；不是概率近似|
|D减少教师重算|位集合、未解决边非单例端点去重|更新幅度、规模、成本诊断|重算少不自动保证完整头更快|
|自适应编码减少字节|full/delta实际包长选择|E01 A/B/C/D、实际编码字节|针对完整传输；B/E/D之间无新增通信收益|
|保持基础训练轨迹|同快照、精确关系、相同目标和学生批次|多轮参数摘要和评估核对|D不额外改变B质量；B自身可塌缩|
|完整头净省时|初始化+所有方法阶段配对计时|E02–E06/E08/E10–E12/E17–E20|依场景成立；负结果、机器波动和空间代价保留|
|公共库或密图越大越好|没有这样的普适理论|E03/E04及固定预算E10|规模和预算必须分开；密图D/E可更慢|
|协作关系稳定提升质量|当前未获充分支持|E09主筛查未过|历史机制问题仍在，不要求ACC增益才能验证计算贡献|
|低公共更新缓解单簇|反馈解释及固定预算/学习率干预|E13–E16/E21/E22|有限配置恢复，不是唯一因果根因或全域稳定定理|
|交接恢复正确且省通信|可靠内存、已知存活名单、原子屏障|E07|正确性回放通过；累计省通信未获支持，未集成完整训练恢复|
|更低内存或能耗|未建立|空间专项显示认证更耗内存；未测能耗|不得把省时写成所有资源同步降低|

编号和全部来源见[实验索引](EXPERIMENT_INDEX.md)。P1本地后续结果不增加随机实例，P2开发smoke不作性能结论；状态见[快照说明](LOCAL_FOLLOWUPS.md)。文献比较与新颖性结论本次没有重做审定。

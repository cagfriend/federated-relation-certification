# E38 · STL-10 快照筛选版外部对照

四组配置各运行 200 轮，包含 IID、Dirichlet α=0.1 及两组既有高风险配置。每组运行 Hetero-SSFL、FLESD、FedMKD 的适配实现各一次，Ours 的保护权重 0 和 0.5 各两次，配对顺序互换。共 28 次独立进程运行，每次有 200 轮记录和 21 个评估点。每组统一为六客户端、K=10、1200 张私有图像、512 张公共图像、1000 张测试图像。[配置与源码](../../experiments/snapshot_external_comparison/README.md)

## 聚类质量与共簇

统一 KMeans 评估在私有样本上拟合后对留出集评分。Ours 用头部概率作为输入，外部适配方法用编码特征。测试同簇率是任取两张不同测试图像被判为同簇的概率。

| 配置 | Ours-0.5 ACC / 测试同簇率 | Hetero-SSFL | FLESD | FedMKD |
|---|---:|---:|---:|---:|
| 1201 IID | 21.50% / 13.51% | 19.88% / 12.00% | 20.42% / 14.07% | 18.47% / 30.35% |
| 1201 α=0.1 | 18.28% / 17.18% | 17.45% / 11.98% | 19.23% / 15.34% | 17.98% / 25.07% |
| 1207 α=0.1 | 19.47% / 13.09% | 16.35% / 12.09% | 19.90% / 14.40% | 17.07% / 32.59% |
| 1208 IID | 18.68% / 14.97% | 15.63% / 13.60% | 19.85% / 15.18% | 18.18% / 22.35% |

Ours 的 ACC 四组均高于 Hetero-SSFL 和 FedMKD。相对 FLESD，一组领先 1.08 个百分点，三组落后 0.43–1.17 个百分点，四组 NMI 都较低。Ours 的 0.5 保护在四组末轮都无原生单簇客户端，最差客户端的最大簇占比最高为 45.1%，出现在 1201 α=0.1。该矩阵包含定向风险案例，结论适用于本组设置及检查点。[逐配置结果与 NMI/ARI](../../experiments/snapshot_external_comparison/results_full/report.md)

四组都观察到教师同簇边率降低，最差客户端的测试集中度两组改善、一组持平、一组上升。直接保护计算约 0.32–0.34 秒，四组配对训练净增时约 0.31–0.41 秒。保留保护为可选项，最差客户端集中度和质量用于后续监测。[八个计时配对](../../experiments/snapshot_external_comparison/results_full/guard_pairs.csv)

## 资源口径和复核

含共同自编码器预训练和方法准备，Ours-0.5 各次约 2.97–8.79 秒，外部适配方法约 75.71–110.92 秒。同配置以 Ours 两次技术重复均值为分母，外部耗时约为 Ours 的 11.0–31.9 倍。快照筛查与必要重放计入准备。Ours 冻结编码器，外部方法继续更新编码器，因此差值反映单线程 CPU 上整套适配实现的工作量。评估、审计、进程启动、磁盘加载在计时之外。通信来自应用层编码字节，上下行分别保留。[耗时与通信明细](../../experiments/snapshot_external_comparison/results_full/runs.csv)

28 次运行的 SHA-256 回执、配置及记录完整性均通过复核。保护开关两侧的选定快照与初始头一致，同方法技术重复的逐轮头摘要、质量与通信一致。16 条 Ours 轨迹共核对 4,915,200 条教师关系，零错误。下一轮用相同训练协议做 B/E/D 对照，以测定关系认证的增量收益。[原始运行与回执](../../experiments/snapshot_external_comparison/results_full/runs) · [后续实验](../NEXT_EXPERIMENTS.md)

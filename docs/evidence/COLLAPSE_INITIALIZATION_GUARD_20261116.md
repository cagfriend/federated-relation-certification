# E34/E35：中心初始化与阶梯分簇保护（2026-11-16）

2026-11-16。已完成本地结果审阅。本次发布结论和绑定文件SHA的精简证据；原始大型轨迹、缓存与本轮实验源码未随本次提交上传。下文的本地路径用于定位原始记录，不表示其已入库。新候选不覆盖历史学习配置。

## 1. 中心初始化：缓解退化，但不能单独修复

seed1201，IID/Dirichlet α=0.1，随机/中心初始化，共4条200轮轨迹；其余配置相同。中心初始化使用同次KMeans中心转换为线性头，不另拟合一组标签。已有私有频数校正仅用于client0/3。

|划分|初始化|最终原生ACC|最大簇占比均值|平均空簇数|
|---|---|---:|---:|---:|
|IID|随机|17.08%|52.53%|4.17|
|IID|中心|17.70%|46.37%|3.17|
|α0.1|随机|16.22%|45.90%|3.83|
|α0.1|中心|17.35%|37.20%|2.67|

中心初始化的12个客户端/划分初始伪标签拟合率均100%。但IID client1首次私有更新就使私有最大簇56%→84.5%、伪标签拟合100%→69%，发生在该轨迹任何公共更新之前。因而初始argmax不匹配和公共更新都不是这次首次集中的必要条件。

正确初始argmax未必有充足间隔；多数伪簇梯度主导是候选解释，尚未直接确认为唯一原因。公共更新在其他阶段仍可能抵消私有修复，不能据首次私有阶段问题认定其无害。

中心组IID最终client1最大簇仍95.6%，client4为61.6%；α0.1 client1为65.3%。中心初始化保留为后续诊断候选基线，不声明普适防坍缩或替换全部历史随机初始化协议。4条累计1,228,800次关系审计零错误。

证据：experiments/head_initialization/results_pilot/；outputs/head_initialization_results_review/REVIEW.md。

## 2. 阶梯保护：持续约束有效，撤除后反弹

每划分9组：无新增约束基线＋弱/强×1–10、1–50、1–100、1–200轮，共18条200轮，仍为seed1201。固定中心初始化，其他训练预算、学习率及已有0/3校正不变。

新增保护在私有SGD中惩罚初始伪簇得分未比最高竞争簇高出0.1的样本，按完整私有伪标签频数进行逐簇等权加权；弱/强权重0.1/1.0。教师、公共BCE、测试使用raw logits。截止轮之后直接调用原私有更新。

下表为第200轮测试集上六客户端的最大簇占比均值，不是公共图同簇边比例，也不是要求真实簇均匀的判据。

|约束|IID|α0.1|
|---|---:|---:|
|无新增约束|46.37%|37.20%|
|弱1–10|46.42%|37.00%|
|强1–10|46.38%|36.82%|
|弱1–50|46.17%|36.75%|
|强1–50|46.25%|36.70%|
|弱1–100|45.97%|36.53%|
|强1–100|46.17%|36.70%|
|弱1–200|41.92%|33.77%|
|强1–200|33.68%|30.70%|

关键关闭证据：IID client1强约束至100轮时最大簇82.3%、8个簇，关闭后110轮变94.5%、3个簇；持续相同约束则110轮为81.6%、8个簇。client4第100轮33.6%，关闭后第110轮60.9%；持续保护最终23.0%。这不支持“早期保护后就会自行稳定”的假设；现有原目标在后续阶段仍存在重新集中倾向。

持续强约束是本轮改善最明显的候选：IID/α0.1最终平均空簇均0.5，原生ACC为19.80%/18.85%，NMI/ARI也改善。但IID client1仍79.6%集中，多个私有伪簇召回仍为零，不能称为充分修复。200轮档没有关闭后观测，不能证明撤除后稳定。

18条完成、源码及设计摘要一致，两基线逐轮复现历史中心轨迹，920次共同前缀检查通过，5,529,600次关系审计零错误。

成本也须保留：持续强约束保护计算约0.21–0.23秒；本次完整头部耗时相对基线约增加15%–19%，累计通信约增加8%–15%。为单次运行描述性计时，不是受控重复性能确认。新增保护不增加消息类型或通信轮次，但改变教师关系及差分编码字节。不能将新增训练目标的改变算作认证贡献。

本轮仅单seed探索；测试检查点、轮数和大量边比较不能视为独立重复。没有预先定义的全面恢复阈值，不用“低于99%”宣布成功。

证据：experiments/early_cluster_guard/README.md、VALIDATION.md、results_pilot/report.md、completed.json、shutdown_checkpoints.csv、test_quality.csv及18份原始runs JSON。

## 3. 下一步：优先检验更低开销的私有校正范围扩展

状态：推荐方案，尚未冻结、未写下一步代码、未启动正式实验。

固定中心初始化、两划分、seed1201、200轮、已有学习率及公共预算，新增“全客户端私有频数校正、无新增间隔保护”的两条轨迹。复用本轮无新增约束基线及持续强约束结果作为参照；必要重放基线时逐轮匹配摘要。第一步仅改变校正适用客户端范围，不同时调强度、温度或公共目标。

实现沿用Balanced-Softmax式私有CE：每客户端以完整固定伪标签计数预计算log(n_k/N)，每个CE批次临时加到logits；参数更新作用于原头。保持教师、公共、测试raw logits。200/300张客户端须支持多个原有私有batch，保留seed401顺序；不能直接调用现有仅适用0/3单batch的入口。不是按预测重新估计频数，也不是强迫非IID预测均匀。

重点评价：client1/4及所有其他客户端的T0→T1、T1→T2最大簇变化，逐伪簇召回、空簇和固定伪标签拟合；测试原生质量作为护栏，资源开销与关系认证正确性同步记录。ACC提高不是计算贡献的前提。

若私有阶段改善、公共阶段持续抵消，再单独设计同设置private-only对照以隔离公共反馈；若仍需持续间隔保护，再考虑针对问题客户端保留或按风险启用保护，并测其实际代价。暂不继续盲延长预热或继续降低学习率。

全客户端校正是待验证候选，不能根据client0/3较健康就认定会成功；客户端间数据、表示及公共权重存在混杂。没有消除严重退化前，不恢复大规模外部baseline计时或宣称学习范围已修复。

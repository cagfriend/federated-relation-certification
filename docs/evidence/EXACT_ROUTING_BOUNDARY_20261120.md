# E41 精确关系生成的选路边界

2026-11-20 审阅。复用 E40 的四个 STL-10 场景、三档公共规模、六客户端、200 轮，按整种子留出拟合静态表。12 次 B 教师轨迹捕获后，每格五条路径各做三次独立单线程重放。主要耗时是包含路径决策、初始化和实际试跑的教师关系生成时间。

## 选路结果与异常

- 静态 S 在 512 档全部走 B。4096 档有 3/4 格对 B 达到平均省时 3% 且至少赢两块。在 16384 档有三个格为部分客户端选 D，四格的平均耗时均高于固定 B。固定路径先测，选路后测。同路径也出现可见的批次间耗时波动。
- C 的 216 次客户端决策中，108 次缺少候选，108 次被回本门槛拦截。实际试跑、切换均为零，与 S 的逐轮路径和重算端点一致。发布结果保留 `1201 IID / M=512` 中 S 的慢重复，完整 200 轮生成用时 0.2382 秒，相邻两次约 0.1425 和 0.1464 秒。C 对 S 的表面 18.11% 优势无法归因于校准，慢重复原因未查实。
- 12 条捕获轨迹的图、教师头与硬关系摘要已与 E40 重新核对。180 份结果回执一致，755,712,000 次关系核对零差异，36 个配对块均通过运行状态检查。逐轮回放日志可从 ZIP 提取，教师参数和特征需要由复现实验生成。

**下一候选**为离散规模规则 `512→B，4096→D，16384→B`。这三个规模来自开发结果。新种子确认及完整头部计时仍待做，切换阈值与跨设备适用范围仍待确定。

# E48–E49 偏置净变化认证

当前 D 用两次真实打分参考之间的类间偏置净变化排除候选簇。权重仍使用沿教师快照累加的移动上界。旧 D 保留作历史复现和显式对照。选择新版的依据是已测矩阵上的计算量、总生成耗时及浮点压力测试的净改善。两个实验按预设规则分别保留原判定。200 轮完整训练和后续数值防护已另行完成。[E50–E53 的结果与当前采用决定](D_AND_NUMERICAL_FALLBACK_20261122.md)

| 证据 | 观测 | 结论边界 |
| --- | --- | --- |
| E48 数值压力 | 21 个实例，52,509 个配对边位置。对全量 float64 B 的错边从 15,354 降至 2,105。修复 13,293 处，残留 2,061 处，新增 44 处 | 纯偏置累计的 13,192 处全部修复。三个相消实例有新增错边，两个权重累计实例仍有 2,040 处错边。零新增门槛未通过 |
| E49 生成开销 | 18 个 STL-10 配置、54 个计时配对、108 个独立进程。六客户端、200 轮。重打分 MACs 降低 17.86%–21.79%，16/18 个配置生成耗时中位数下降 | 54 对的生成时间合计从 173.13 秒降至 158.57 秒，节省 8.41%。总和按实际运行时长加权，包含初始化 |
| E49 一致性与资源 | 重复运行合计 453,427,200 次逐边比较零差异，逐轮通信字节相同。每配置六客户端持久缓存减少 480 字节 | 证据限于已测教师轨迹。进程峰值和持久缓存分别记录 |
| E49 预设确认组 | M4096、种子 2022/2023，IID 汇总省时 8.76%，强非 IID 汇总省时 3.62% | 强非 IID 的种子 2023 慢 6.89%，超过单配置 2% 容差。IID 通过，强非 IID 未通过。完整头部及端到端时间待测 |

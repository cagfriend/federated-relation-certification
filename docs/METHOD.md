# 当前方法概述

## 目标与知识形式

目标是在同模型家族、不同宽度或特征维度的客户端之间进行无监督样本聚类协作，同时降低关系知识生成和传输开销。CNN不是方法前提；当前实验采用不同宽度的MLP。真实训练已覆盖IID和容量约束的类别比例非IID＋模型宽度异构；训练仍是固定聚合者、全员在线的串行内存模拟，动态半分布式部署尚未集成验证。

交换的是公共无标签样本对的二值关系：两个样本在该客户端的本地预测中是否同簇。不同客户端不必对齐簇编号；编号只在各客户端内部比较。当前代码各客户端共同使用K=10。

临时聚合者为每条边维护各客户端已提交的关系，以及同簇判断计数。等权计数除以客户端数，就是公共关系学习目标。当前没有使用贡献度加权，没有聚合模型参数、梯度或层通道。

## 基础训练流程

1. 约定公共样本库、固定样本对图和边编号。当前先用各客户端自己的私有无标签图像训练自编码器，再冻结编码器，在私有特征上运行一次K-means产生固定伪标签。
2. 每轮客户端先用私有伪标签进行交叉熵更新，只训练线性聚类头。
3. 固定本轮教师头快照，生成约定图上所有边的硬关系。
4. 客户端提交关系；聚合者更新同簇计数，并把计数目标下发。
5. 客户端用收到的计数比例做公共关系BCE训练。预测两个端点的簇概率，以概率向量内积作为同簇概率；每个学生批次都用当前头重新前向和反向。
6. 保留已提交关系与教师认证缓存，进入下一轮。

这里的固定私有伪标签CE只是已经落地的基础学习目标。它不是一个已证明优于Local的完整新聚类学习目标，邻域一致性、防坍缩损失等尚未加入当前实现。

## 关系认证：减少教师计算

第一轮完整计算公共样本，保存每个样本实际计算时的获胜簇、相对其他簇的分数间隔、特征范数及认证参考状态。

后续轮次固定教师快照后，根据两次教师快照之间线性头参数的变化，累计各簇对分数差的保守变化预算。从某样本最后一次真实计算的状态出发，排除不可能超过当时获胜簇的类别，得到当前真实获胜簇应包含在内的候选集合。

对每条边检查两个端点的候选集合：

- 集合不相交：一定不同簇，即使两个端点各自的具体标签尚不确定，也可以直接确定关系为0。
- 两者都是相同的单元素集合：一定同簇，关系为1。
- 其余情况：关系尚不能确定；收集这些边上标签不确定的端点，去重后做真实教师计算，再确定全部关系。

例如，一端候选为{1,2}，另一端为{3,4}，普通标签认证无法确定两端具体标签，但关系认证已经知道它们一定不同簇。这是D相对逐样本认证E的主要机制差异。

只有真实计算某样本时才刷新它的参考缓存。长时间跳过样本时，变化预算必须从其最后一次真实计算累计，不能只看最近一轮。下一轮教师变化还必须包含前一轮公共学生更新和本轮私有更新；公共训练后不能错误重置教师参考快照。

当前认证基于固定特征和线性头。候选集合采用uint64位集，支持1至64个簇；浮点误差采用保守数值保护，尚不是完整IEEE浮点形式证明。原始实验每轮另用全量前向作oracle核验，但该额外审计不计入方法性能时间。

## 自适应通信：减少发送字节

上行比较当前硬关系与该客户端上次已提交关系；下行比较当前计数向量与各客户端已提交计数向量。编码支持：

- 完整位打包向量；
- 变化边编号，加上行翻转方向或下行新计数；
- 无变化确认。

根据实际编码长度选择较便宜的形式，而不是硬设“若干epoch后必须用差分”。因此训练初期变化多时可发完整向量，后期变化稀疏时可发变化列表；此逻辑也允许后来重新切回完整向量。

消息包含图标识、任期和版本，并验证接收/提交确认。初始化图注册与控制消息计入通信成本；原始公共图像和预置特征的分发未计入通信。领导节点自己的本地处理不算网络消息。

当前协议固定客户端成员、leader=client 0、term=1，内存中同步传递消息；没有真实选举、网络丢包、任期迁移或故障共识实现。

## 对照与创新定位

| 方法 | 教师关系生成 | 传输 |
|---|---|---|
| B | 每轮每个公共样本完整计算一次，再生成图关系 | 自适应完整/差分/无变化 |
| E | 逐样本标签认证，不确定标签做真实计算 | 相同编码 |
| D | 直接认证关系，仅计算未解决边的必要端点 | 相同编码 |

早期合成实验另有A=全量计算＋完整传输，C=关系认证＋完整传输，便于拆分计算和通信收益。

当前相对贡献是：在同一硬关系学习目标、同一参数轨迹和同一提交协议下，利用关系可确定而标签未必确定的情况，进一步避免教师计算。它不是首次使用公共样本蒸馏、首次使用变化检测或首次使用差分编码的主张。完整论文定位与文献排重仍需另行完成，当前仓库不把旧候选想法当作已证明的新颖性结论。

# 后续实验：计算与资源优化
更新：2026-10-31。主贡献是降低关系知识生成与整体训练的计算开销。允许预先约定范围内的小幅质量下降；ACC提高、协作优于Local或解释跨客户端知识的学习收益，均不作为后续实验的前提。

## 统一验收口径

- 主指标：同配置、同seed的D/B和D/E完整头部耗时、含准备成本耗时、绝对省秒及跨seed稳定性。生成阶段省时和生成占比用于解释整体收益。
- 资源代价：持久数组、隔离进程峰值、通信字节；同时披露时间收益与空间代价。
- 质量护栏：比较不同训练预算时，默认沿用最终平均ACC下降不超过1个百分点；NMI/ARI、最差客户端与簇占用辅助记录。后续改变护栏须在运行前确定，不能根据结果调整。
- 同一训练配置内，精确认证D仍须与B/E保持关系、接收目标、参数及评估一致。允许的质量下降来自训练预算等设置变化，不允许用错误认证换省时。
- 同预算下的认证收益与减少训练预算的收益分列。不将二者合并为认证算法加速，也不把串行客户端总耗时称为并行轮时延。
- 人工暂停单独记录并按共同轮掩码剔除计时，不计故障；原始记录保留，不估算替换暂停时间。

## 1. 已完成：减少私有头部训练工作负载

正式18组、54条B/E/D轨迹与18次完整私有档内存回放已审核。固定M16384、degree1、K10、公共8步，私有上限完整/2048/1024；编码器始终完整私有预训练，不能称为小私有数据集实验。

2048档D/B完整头省时中位IID22.01%、强非IID22.81%；D/E省5.32%/2.83%，两个划分各3/3较快。平均ACC护栏5/6通过，强非IIDseed404下降3.06个百分点，应保留为质量越界。1024档D/B省27.72%/31.94%，但D/E慢1.26%/2.54%，平均ACC六组均越界，强非IID下降约25–27个百分点，停止将其推荐为“小幅下降”的可用配置。

所有同预算B/E/D关系、参数、目标和评估一致；计算正确性通过。预算缩减自身的收益与认证收益分开报告。原始计时存在B generation 36.89秒及E public 15.03秒离群，原因未确认，本次保留全部轮，不自行归为人工暂停或故障。

下一步只推荐第2项独立性能确认，2048是待确认候选，不是已普适最优。完整档和1024结果继续保留为边界；不为取得正ACC反复改损失，不将这次探索性计时当作独立性能复核。

## 2. 独立性能确认

冻结既有配置和实现，选择代表性场景与尚未参与探索的新seed；数量、技术重复次数、主指标和汇总方式在执行前确定。平衡方法顺序，控制线程/设备负载，分别测单方法独立进程；用参数、关系目标和消息摘要核对学习轨迹。

区分训练实例差异与同一实例的计时波动。报告逐seed配对比、绝对秒差、区间和胜出数；200轮、六客户端或大量边检查不是独立性能样本。生成阶段、完整头部和含准备成本分别报告，内存回放耗时不能拿来替代正式测速。

记录人工暂停；使用共同轮掩码维护算法和预算配对公平。当前两次暂停已按用户指示处理，不据此要求重跑全部既有实验，也不计入容错失败。

验收针对计算收益的稳定性，不针对准确率提高。该确认与此前事后提出的degree×width静态选路规则验证是不同任务，后者继续暂缓。

## 3. 第二数据集与公共库分布

保留STL-10作为大公共参考库、小私有数据的候选，具体数据协议与预训练来源在实施前验证并冻结。先保持编码器冻结、同模型家族异宽、稀疏图和固定公共更新预算。

分开控制公共库大小、类别覆盖/比例偏斜及分布偏移。主要看生成占比、认证/回退成本、完整流程省时、准备成本和内存。质量只检查是否在可接受范围及是否出现严重退化，不把协作胜Local或提高ACC设为继续条件。

构图或预训练若增加计算、通信或缓存，全部计入。若只在部分公共分布下有收益，将其写为使用条件。不会因为一个数据集结果不利就选择性隐藏。

## 5. 内存与准备成本

当前大M认证相比B有额外峰值内存，需在不同公共规模和设备容量下报告时间—内存取舍。已有分块、位集合、端点去重工作保留；只有新定位的真实瓶颈才安排进一步工程优化，并以零关系误差和净省时/峰值下降验收。

C0完整记录预训练、特征提取、缓存和KMeans，区分冷准备与缓存复用。固定最大公共池共享准备政策须明确，不能将复用缓存记作零成本，也不将共享政策直接解释为每个M的最小部署成本。能耗只有实际测量后再报告，不能由秒数推定已省电。

## 6. 数值有效性

已有整数性质、漂移、K边界、平局及随机浮点压力测试证据；剩余专项是极小间隔、大尺度、长前缀累加/相减和边界舍入。用独立高精度或有理数小实例作参考，明确真实算术与指定float64教师前向的区别，保存可重放输入。

验收为零错误认证；不确定则回退，并把回退代价计入性能。有限测试不是完整浮点证明。该项保障计算优化正确性，与提高ACC无关。

## 条件扩展

- **真实训练恢复：** 若扩大半分布式部署主张，再验证已提交目标只消费一次、模型/优化器/教师缓存和随机状态一致恢复；参考执行使用相同成员/故障日程，计入交接/重试/检测/选举及关键路径开销。现有受限协议实验保留，不把人工暂停视为故障。
- **编码器更新：** 固定特征前提改变前，先设计缓存失效、刷新或重建。B与带重建D使用相同更新日程，完整计入特征刷新与重建成本；若限定冻结表示，可列后续工作。
- **学习目标改进：** 仅在今后明确要求研究学习算法时另立任务。Mean目标、贡献加权、互补客户端选择及追求更高ACC均不属于当前必做实验。

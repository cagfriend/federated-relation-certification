# 后续研究顺序（聚合者恢复协议实验后）

关系认证、公共库规模、图密度、成本分解、连续缓存选路及聚合者恢复协议实验已有记录。动态选路、当前按需交接和热备均未证明额外资源收益，保留负结果。恢复功能只在受限内存协议模型下通过，不视为实际训练/网络集成完成。

1. **非IID＋模型宽度异构是必做主场景，尚未运行。** 先类别比例偏斜，再缺类/数量不均；带Local及完整协作基线，区分协作质量与认证省时，报告质量、总耗时/字节、初始化和内存。无监督训练不使用私有真标签。
2. 协作相对Local的稳定质量收益仍未建立；如非IID基线也缺乏收益，单独补强本地/公共学习目标，不把目标改变混作认证收益。
3. 接回真实训练的恢复集成仍待做：学生只能消费提交目标，模型/优化器/教师缓存恢复须单独设计和测试。真实网络、故障检测、提交传播故障、分区与选举协调成本不在本轮已验证范围。
4. 编码器更新/更多模型任务仍待扩展；固定特征的证书不能直接跨特征变化沿用。认证底层实现改写仅为可选工程优化，不重复列为未验证主创新。
5. **按用户要求暂缓新seed静态选路复核。** degree×width候选来自事后分析，若以后恢复，须先冻结再独立验证；不继续在原seed调动态阈值以寻找正结果。
6. 贡献加权、互补客户端选择等候选尚未验证，优先级靠后。论文定位围绕已证实的关系生成省算及适用边界，不把未获支持的恢复机制写成通信创新。

依据：[恢复协议审阅](../outputs/aggregator_recovery_results_20261030/RESULTS_REVIEW.md)、[选路审阅](../outputs/path_selection_results_20261030/RESULTS_REVIEW.md)、[成本诊断](../outputs/cost_diagnostics_results_20261030/RESULTS_REVIEW.md)。不据合成trace、三个seed和受限故障模型推断通用部署收益。关系认证自身没有在共同编码基础上额外减少通信字节。

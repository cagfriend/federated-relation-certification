1. **验证完整头部收益。** 在 E49 主场景 M4096、IID 与强非 IID、种子 2022/2023 下，冻结学习协议并配对比较当前 D 与 B。记录生成、私有更新、公共更新、提交和完整头部耗时，逐轮核对关系、学生目标和头参数。采用轮换顺序和独立单线程进程。事前单列强非 IID 种子 2023，检查生成阶段波动能否复现。ACC、簇占用用于核对轨迹及退化。
2. **定位相消与权重累计边界。** 复用 E48 的三个新增错边实例和两个权重累计实例。逐个区分候选排除、局部回退相对全量打分的差异。针对已确认机制测试修复，按相同边编号报告修复、残留和新增，并计入触发次数与额外计算。
3. **重新核对当前 D 的比较边界。** 用相同预算比较 B、E、当前 D 与 Demand，检查原 512/4096/16384 选路结论在新版下的适用范围。保留历史对照原始判定。
4. **暂缓跨环境复测。** 第二计算环境可用时，再冻结新版、精度和线程设置，按[跨环境设计](CROSS_ENVIRONMENT_ROUTING_PLAN.md)更新比较对象。

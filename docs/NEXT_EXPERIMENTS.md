# 后续研究顺序（非IID异宽实验后）

类别比例非IID＋模型宽度异构已完成，包含强偏斜下自然缺类，不能继续列为完全未验证。关系认证在该固定特征、degree1场景中保留省时与精确性；协作质量提升仍小且指标不一致。动态选路与聚合者恢复的负资源结果继续保留。

1. **优先诊断协作学习质量。** 分析私有/公共损失及梯度量级、公共关系目标信息量、逐客户端受益和簇集中现象；先解释为什么B与Local差异较小，再决定是否单独改学习目标。学习目标改动必须与认证省算实验分开。
2. 非IID扩展仍待：数量不均、受控缺类或其他分布偏移；现有固定容量Dirichlet实验只覆盖类别比例偏斜及自然缺类。其他数据集/模型家族、更多公共样本或degree的非IID组合也尚未验证，不把IID公共库规模结论直接外推。
3. 真实训练的聚合者切换/恢复集成待做：学生只消费提交目标，模型/优化器/教师缓存状态单独恢复。既有合成协议实验不覆盖真实网络、故障检测、提交传播中故障、分区或选举协调。
4. 编码器更新仍待设计新的有效性条件或重建机制；当前证书不能直接沿用到特征变化。底层认证工程优化已有实现，不重复列为未验证核心创新。
5. **新seed静态选路复核按用户要求继续暂缓。** 已测degree×width拆分来自事后分析；恢复时先冻结规则再独立确认，不在原seed追调动态阈值。
6. 贡献加权、互补客户端选择等优先级靠后。当前论文证据支持关系生成省算及边界；认证没有在共同自适应编码上额外省通信。

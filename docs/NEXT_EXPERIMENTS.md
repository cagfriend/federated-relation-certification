# 后续实验：计算与资源优化
更新：2026-11-01。主贡献是降低关系知识生成与整体训练的计算开销。允许预先约定范围内的小幅质量下降；ACC提高、协作优于Local或解释跨客户端知识的学习收益，均不作为后续实验的前提。

## 统一验收口径

- 主指标：同配置、同seed的D/B和D/E完整头部耗时、含准备成本耗时、绝对省秒及跨seed稳定性。生成阶段省时和生成占比用于解释整体收益。
- 资源代价：持久数组、隔离进程峰值、通信字节；同时披露时间收益与空间代价。
- 质量护栏：比较不同训练预算时，默认沿用最终平均ACC下降不超过1个百分点；NMI/ARI、最差客户端与簇占用辅助记录。后续改变护栏须在运行前确定，不能根据结果调整。ACC提升不是计算贡献的前提，但接近单簇的严重退化不能解释为可接受的小幅质量下降，也不能据此声称已在有用聚类任务上完成迁移。
- 同一训练配置内，精确认证D仍须与B/E保持关系、接收目标、参数及评估一致。允许的质量下降来自训练预算等设置变化，不允许用错误认证换省时。
- 同预算下的认证收益与减少训练预算的收益分列。不将二者合并为认证算法加速，也不把串行客户端总耗时称为并行轮时延。
- 人工暂停单独记录并按共同轮掩码剔除计时，不计故障；原始记录保留，不估算替换暂停时间。

## 4. 规模与异构维度

|维度|控制方式|重点指标|
|---|---|---|
|簇数K|训练支持2–64，认证核心支持1–64；分档固定其余设置|类别对预算、候选维护、回退时间和峰值内存|
|客户端数N|分别固定总私有量、固定每客户端私有量；不复制样本伪造规模|计算总量、关键路径、聚合负载、通信|
|私有数量不均|先固定类别比例再改变容量|各客户端计算负担与聚合成本；质量作护栏|
|公共图|在固定学生预算下改变M/degree；可再比较邻域图|生成成本、端点覆盖、构图/同步开销及净省时|

同家族异宽是当前要求；不同模型家族属于可选扩展，不是必须补齐的前置任务。已有类别比例非IID含自然缺类，不重复写成非IID或缺类完全未验证。

## 5. 内存与准备成本

当前大M认证相比B有额外峰值内存，需在不同公共规模和设备容量下报告时间—内存取舍。已有分块、位集合、端点去重工作保留；只有新定位的真实瓶颈才安排进一步工程优化，并以零关系误差和净省时/峰值下降验收。

C0完整记录预训练、特征提取、缓存和KMeans，区分冷准备与缓存复用。固定最大公共池共享准备政策须明确，不能将复用缓存记作零成本，也不将共享政策直接解释为每个M的最小部署成本。能耗只有实际测量后再报告，不能由秒数推定已省电。

## 6. 数值有效性

已有整数性质、漂移、K边界、平局及随机浮点压力测试证据；剩余专项是极小间隔、大尺度、长前缀累加/相减和边界舍入。用独立高精度或有理数小实例作参考，明确真实算术与指定float64教师前向的区别，保存可重放输入。

验收为零错误认证；不确定则回退，并把回退代价计入性能。有限测试不是完整浮点证明。该项保障计算优化正确性，与提高ACC无关。

## 条件扩展

- **真实训练恢复：** 若扩大半分布式部署主张，再验证已提交目标只消费一次、模型/优化器/教师缓存和随机状态一致恢复；参考执行使用相同成员/故障日程，计入交接/重试/检测/选举及关键路径开销。现有受限协议实验保留，不把人工暂停视为故障。
- **编码器更新：** 固定特征前提改变前，先设计缓存失效、刷新或重建。B与带重建D使用相同更新日程，完整计入特征刷新与重建成本；若限定冻结表示，可列后续工作。
- **学习目标改进：** 仅在今后明确要求研究学习算法时另立任务。Mean目标、贡献加权、互补客户端选择及追求更高ACC均不属于当前必做实验。

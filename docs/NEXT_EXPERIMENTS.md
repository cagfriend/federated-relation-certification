# 后续研究顺序（图密度实验后更新）

图密度实验已完成，不再列为待办，也不继续以加密图扩大省时作为主方向。

1. 先解释D/E适用边界：稀疏图有额外收益，密图重算端点并集扩大，D/E优势消失；保存负结果。
2. 评估低成本E/D路径选择是否可行。任何切换必须保持相同快照、关系、目标与学生更新，不得把近似或减少训练预算混入。此项仅为待验证候选，未实现、未做本轮新颖性验证。
3. 再处理特征/编码器更新，需要新的正确性处理，不能直接套用固定特征认证。
4. 再扩展数据非IID与真实临时聚合部署；分别验证聚类质量、开销和恢复状态，不把串行模拟当部署结果。

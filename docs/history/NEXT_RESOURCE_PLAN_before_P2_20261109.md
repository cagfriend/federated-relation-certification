# 公共学习率0.05后的实验计划

2026-11-06。当前优先目标转向固定0.05候选下的精确关系认证与资源收益。STL-10两轮干预已完成，原问题与证据见[退化处理记录](PUBLIC_LR_RECOVERY.md)。后续阶段按结果门槛推进，具体代码与执行协议在运行前冻结。

## P1，恢复同配置B/E/D对照

沿用公共学习率确认的8个配置，每个重新运行B/E/D各一次，共24条200轮轨迹。原诊断记录只用于质量与参数轨迹锚点。两模型场景及配置如下。

|场景|强非IID健康seed|强非IID已知失败seed|新seed及划分|
|---|---|---|---|
|N12/K10|1001|1003|1101，IID与强非IID|
|N6/K64|1001|1002|1101，IID与强非IID|

固定公共2步、有效学习率0.05、私有学习率0.1、完整私有epoch、200轮、M16384、degree1与本轮学习率确认的8份输入清单。缓存出处固定为experiments/public_lr_confirmation/results_full/inputs，逐份校验base_metadata_sha256及适用的k_metadata_sha256。seed1101的AE、特征和伪标签来自本轮新准备数据，直接复用其缓存。所有方法从同一初始头开始。0.05通过public_weight=0.5设置。实验使用新入口，旧包中的默认配置继续对应其历史协议。

必须逐轮精确匹配B/E/D的关系、提交计数、接收目标、私有样本和更新量、公共边顺序、损失和参数摘要。共同20轮检查点上的评估匹配已有0.05诊断锚点。诊断探针放在计时阶段外，使用实际生产训练step测量阶段及完整头部耗时。

主指标为同配置D/B、D/E完整头部耗时比与绝对省秒，另列准备加加载加头部、生成占比、教师重算端点、认证维护、公共/私有/聚合耗时、序列化通信字节和持久数组。相同配置下计时与字节按原始运行保存。

增加6次隔离内存回放，固定N12/K10/强非IID/1001与N6/K64/强非IID/1002，各B/E/D一次、关闭oracle和评估。核对训练轨迹及方法专属工作量。该范围只提供两配置的峰值观察。

P1属于一次/方法的探索性资源对照。若任一精确性检查失败，先修正实现。若出现新严重退化，先审查该配置的学习或复现问题。全部结果保留，逐配置公开D/E负收益。八配置结构、过程及适用质量护栏沿用public_lr_confirmation已冻结标准。

## P2，固定配置的重复计时

在P1的精确性及质量复现通过后，按预先选定的4个强非IID配置进行3次技术重复，每次B/E/D独立进程，共36次方法运行。

- N12/K10，seed1001与1101。
- N6/K64，seed1002与1101。

四配置在P1结果产生前列出，用于覆盖原D/E不利条件、K64原失败条件和新seed。每个配置的3次重复分别采用BED、EDB、DBE顺序，使同配置每个方法都占据每个位置一次。运行时记录电源状态，条件允许时记录频率与温度。技术重复用于估计机器计时波动。

报告每配置每次匹配重复的D/B、D/E比值与省秒，再报告重复均值、中位数、范围及方向一致性。四配置逐项解释，新seed1101仍为同一个随机实例。运行前在新协议中冻结实际意义门槛；建议将D/B完整头的配对重复中位省时比例≥10%、D/E≥3%、各比较至少2/3重复方向一致作为该配置的推荐标准。小于门槛的观测仍如实报告其数值，负收益继续作为适用边界。

在0.05候选的计算证据明确后，先安排固定每客户端400张的等量规模实验；私有数量不均另立实验，运行前冻结每客户端分配矩阵、总私有预算及类别覆盖。使用新实验包显式配置0.05，沿用旧包所需的源码及缓存身份检查。原fixed_per_client代码默认仍是公共有效学习率0.1，执行新版协议需相应的新入口。

根据测得的瓶颈决定是否补更多K/N/公共图条件。新seed静态选路复核继续暂缓。模型持续更新、真实训练故障恢复及数值边界等作为后续独立范围扩展。

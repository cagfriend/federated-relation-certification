# 单簇退化：观察、解释与当前处理

研究主目标是计算优化，可接受预定范围内小幅质量下降；接近随机水平的持续单簇不属于小幅下降。精确认证只保证复现相同基础方法，不保证基础学习目标不会退化。

## 证据链

1. STL-10原公共8步配置的B/E/D轨迹一致，但12配置全部严重退化。不是D单独引入的近似错误。
2. seed1001/IID/40轮P仅私有0/6单簇、J联合6/6、F冻结首轮目标3/6，支持公共更新与反馈参与的解释。
3. 公共1/2步短程末轮未塌缩；随后8条200轮新选档轨迹通过预定护栏，按先定规则选2步。
4. 扩展到K64或N12后，公共2步、有效学习率0.1仍可迟发退化。低步数不是普适修复。
5. N12诊断中仅将公共有效学习率减为0.05，保持2步和相同图，也能恢复；仅私有分支早期同样可能短暂集中。
6. 公共0.05确认的8配置均通过结构/过程/NMI标准，适用的5项平均ACC副作用护栏通过。新增seed只有1101；P1成本实验复现其相同质量轨迹，不新增独立随机实例。

## 机制解释

公共损失把 $q=p_i^\top p_j$ 拉向聚合关系目标。如果大部分教师硬关系逐渐为正，集中到相同簇能降低这部分BCE；更集中的预测又产生更多同簇关系，形成正反馈。较强公共更新可能压过私有固定伪标签约束。

这是与干预结果一致的解释，不能排除表示质量、随机头初始化、伪标签和早期私有训练的共同作用。目标本身存在退化解压力，不意味着任意数据或任意公共权重都会塌缩。

## 当前处理与没有改变的部分

后续STL-10候选保留公共2步，`head_lr=0.1`，`public_weight=0.5`，公共有效学习率0.05；没有引入新损失、预热、均衡项或动态触发器。此候选不是历史所有实验的设置。

减少公共步数改变信息消费与工作量，应单列预算收益；只降低公共学习率保持同样步骤和边预算，改变参数轨迹与认证率，其成本收益要重新测量。两种措施都不能算作关系认证自身贡献。

检查逐客户端簇占用、最大簇比例、教师正边率与NMI/ACC/ARI；不能只看平均ACC。检查点之间的瞬时行为没有被全部观测，200轮通过也不保证500轮不退化。长期是否加剧或缓解取决于轨迹，不能单凭轮数推断。

完整数值与原始边界见[PUBLIC_LR_RECOVERY.md](../PUBLIC_LR_RECOVERY.md)、[实验索引E13–E22](../evidence/EXPERIMENT_INDEX.md)、[P1本地快照](../evidence/LOCAL_FOLLOWUPS.md)。后续计划原文保持不变。

# 学习流程与教师/学生时序

## 初始化与异构

各客户端用自己的私有无标签图像训练自编码器，随后冻结编码器 $f_c$。在本地固定特征上运行一次KMeans，得到固定伪标签 $\hat y_{c,i}$。实际线性头随机初始化；KMeans中心不是头部初值。当前数据真标签只用于构造受控划分与评估，不作为私有CE训练目标。

同模型家族不同宽度/潜变量维度是当前模型异构。CNN不是前提；每客户端可以有不同的固定特征维度。公共图只统一样本身份和边ID，无需跨客户端对齐特征坐标或本地簇编号。硬关系接口从概念上允许不同K，但当前正式对照在配置内使用共同K。

## 损失

$$p_{c,i}=\mathrm{softmax}(W_cf_c(x_i)+b_c),\qquad
\mathcal L_{private}=-\frac1{|B_p|}\sum_{i\in B_p}\log p_{c,i,\hat y_{c,i}}.$$

公共边e=(i,j)的学生同簇概率为 $q_{c,e}=p_{c,i}^{\top}p_{c,j}$，目标 $\tau_e=n_e/N$，损失

$$\mathcal L_{public}=-\frac1{|B_E|}\sum_{e\in B_E}\{\tau_e\log q_{c,e}+(1-\tau_e)\log(1-q_{c,e})\}.$$

实现将q裁剪至`[1e-12,1-1e-12]`并使用对应裁剪导数，两端点都回传梯度。两个阶段按顺序SGD，不是先把两项梯度相加再一次更新。

`head_lr=0.1`用于私有阶段，公共有效步长为`head_lr * public_weight`。因此`public_weight=0.5`在当前普通SGD里表示公共有效学习率0.05。公共步数是另一独立参数，不能与学习率、图边数混称。

## 每轮时序

1. 用本地固定伪标签执行私有CE，更新头。
2. 复制当前头为教师快照；本轮生成关系时保持它不变。
3. 首次全量打分；后续按B/E/D生成完整图的精确关系。
4. 编码、聚合并提交同簇计数；学生只消费已提交目标。
5. 每个公共边batch取唯一端点，以**当前学生头重新前向**，计算概率内积、BCE和双端梯度，再更新头。
6. 保存通信提交状态；教师认证缓存只按实际计算规则刷新，进入下一轮。

“前向复用”在此指固定特征复用和**单个学生batch内端点去重**。不能跨SGD批次复用过时logits/计算图，也不能用缓存教师标签代替学生概率。当前NumPy实现显式计算解析梯度，没有框架自动求导图，但每批重新计算和反向的语义相同。

公共全图生成与公共学生训练预算不同：固定步数实验仍生成约定图全部关系，但只消费边随机排列前缀的若干batch。全图遍历版则训练完整图。跨实验版本依原协议，不把某一版描述成所有实验默认。

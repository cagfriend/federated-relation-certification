# 临时聚合者与恢复：框架、已验证部分和边界

## 桌面TXT的框架意图

聚合者从现有客户端中产生，是临时职责；稳定运行不必每轮轮换，主动退出或掉线才触发重新选举。聚合对象是关系，不因聚合者更换而变成模型参数。贡献权重、基于资源或信任的复杂选举属于原始设想，不是当前训练默认能力。

## 主训练实现

固定leader=client0、term=1、全员在线、可靠内存串行交付。真实编解码、图注册、ACK与提交校验已实现；没有socket、实际选举、丢包或模型训练状态恢复。因此准确名称是“面向半分布式框架的关系生成与传输实现”，不能从串行实验推断部署容错和并行时延。

## 独立恢复实验

[aggregator_recovery](../../experiments/aggregator_recovery/README.md)独立比较rebuild、on_demand和hot_backup。它用合法样本标签轨迹生成关系，序列化交接状态并注入部分上传/下发故障。恢复回到最后已提交版本，丢弃未提交暂存，剔除故障成员旧贡献；成员重入以新全量状态登记，不补历史轮次。分母按当前active成员数计算。

18组54条协议回放正确性通过，但累计通信节省未获支持：on_demand在线交接总字节约多0.17%，热备多9.3%–23.1%，持久数组多33.3%。不能只计算故障瞬间少发多少，忽略日常复制、ACK和重新同步。

该实验依赖已知存活名单、可靠内存和原子提交屏障，排除提交决议传播期间故障，未保存或恢复完整训练模型/教师缓存。重复包幂等仅限声明的事务范围。把恢复接进真实训练，以及真实多进程传输和故障检测，仍按既有后续计划推进，本次不改计划。

# 从教师分差认证样本对关系

D 适用于固定特征、可训练线性头和固定公共样本图。样本最后一次实际打分时记录参考快照 a、赢家 h 和它相对各簇 k 的分差 g。标签相等定义同簇，平局取最小本地簇编号。

设 q(h,k,t) = b_k(t) − b_h(t)，表示竞争簇相对缓存赢家的偏置。在当前快照 t，计算

```text
权重预算 = 特征的二范数 × 从 a 到 t 各步类间权重增量差的二范数之和
偏置净变化 = q(h,k,t) − q(h,k,a)
竞争簇能追回的分差上界 = 权重预算 + 偏置净变化
保留条件 = 缓存分差 ≤ 上界 + 浮点保护项
```

权重预算来自 Cauchy–Schwarz 不等式及三角不等式。偏置对两个簇分差的贡献可以直接相减，符号必须保留。实数运算中，若缓存分差大于上述上界，则竞争簇当前仍低于 h。因此包含所有未被排除簇的候选集合也包含当前赢家。

两端候选集合不相交时判异簇，两端是相同单例时判同簇。其余边提取仍有歧义的端点，去重后真实打分。每个样本仅在真实打分时刷新赢家、分差、权重前缀参考行和偏置差参考行。每轮更新共享权重前缀和当前偏置差表。学生更新后沿用教师参考。

浮点实现沿用经验保护项 `1e-10 * (1 + abs(bound) + abs(gaps))`。权重前缀的舍入与相消后的局部回退仍可造成关系差异。E48 覆盖的纯偏置累计错边全部消除，三个相消实例出现新增错边。E49 真实轨迹对全量 B 逐边一致。[数值与资源证据](../evidence/ENDPOINT_BIAS_20261121.md)

# 关系认证：推导、精确回退与缓存

## 1. 要保持的对象

优化前后使用同一教师快照、同一公共图、同一硬关系目标。目标不是容忍少量错误标签，而是在可认证时不求具体标签，仍生成与全量计算一致的关系。

固定客户端，公共样本特征为 $z_i$，线性头为 $W,b$，分数与标签为

$$s_{ik}=w_k^\top z_i+b_k,\qquad y_i=\arg\max_k s_{ik},\qquad r_{ij}=\mathbf{1}[y_i=y_j].$$

`numpy.argmax`在平局时选最小本地簇编号。不同客户端可用不同编号；一个客户端的候选集合只能和它自己的集合比较。

## 2. 从分差到候选集合

样本 $i$ 最后一次真实教师计算发生在快照 $a_i$，当时赢家为 $h_i$，缓存分差

$$g_{ik}=s_{i,h_i}^{(a_i)}-s_{ik}^{(a_i)}.$$

相邻教师快照 $u-1\to u$ 的参数增量记为 $\Delta w_k^{(u)},\Delta b_k^{(u)}$。冻结特征时，Cauchy–Schwarz不等式和三角不等式给出分差变化界：

$$B_{ik}^{(t)}=\|z_i\|_2\sum_{u=a_i+1}^{t}\|\Delta w_{h_i}^{(u)}-\Delta w_k^{(u)}\|_2
+\sum_{u=a_i+1}^{t}|\Delta b_{h_i}^{(u)}-\Delta b_k^{(u)}|.$$

所以当前分差至少为 $g_{ik}-B_{ik}^{(t)}$。若这个值严格大于0，$k$ 不可能超过旧赢家；所有没有被排除的簇组成

$$C_i^{(t)}=\{k:g_{ik}\le B_{ik}^{(t)}+\epsilon_{ik}\}.$$

旧赢家本身的分差为0，也被保留。实数精确运算下取 $\epsilon=0$ 即可；实现增加保守浮点保护。当前赢家一定属于候选集合，是后续关系认证的依据；候选集合不是预测概率或置信区间。

**包含关系的证明：** 若当前赢家为 $k$，则当前 $s_{i,h_i}-s_{ik}\le0$。又有当前分差 $\ge g_{ik}-B_{ik}$，于是 $g_{ik}\le B_{ik}$，因此它没有被候选规则排除。平局使用非严格保留，不能将 `<=` 改成 `<` 来追求更高认证率。

## 3. 为什么比逐样本认证更省

|条件|可以精确断言什么|
|---|---|
|$C_i\cap C_j=\varnothing$|两端不可能同簇，关系为0|
|$C_i=C_j=\{k\}$|两端都只能是簇k，关系为1|
|其他情况|暂不能断言，回退真实教师计算|

例如 $C_i=\{1,2\}$、$C_j=\{3,4\}$。E为了知道两端标签，需要重算两个端点；D已经知道关系为0，可以跳过。若两端均为 $\{1,2\}$，不能因为集合相同就断言同簇。

收集未解决边的端点，只保留候选非单例的样本并去重，然后真实计算其当前标签。单例端点不需要重算。重算后再次检查整个约定图，确保所有边都可确定；只刷新真正求过教师分数的样本缓存。

## 4. 实现中的累计前缀

类对前缀记录 $P^W_{ab}(t)=\sum_{u\le t}\|\Delta w_a^{(u)}-\Delta w_b^{(u)}\|_2$，偏置另记相同形式的绝对差前缀。每个样本保存最后真实计算时赢家对应的前缀行。当前行减去旧行，就得到它自己的累计预算，无需保存所有历史头参数。

缓存包括：固定特征范数、旧赢家、旧分差、参考前缀行、真实计算位置，以及生成器上一次教师头参数。已提交关系属于通信状态，和认证参考不是同一套缓存。

两个容易混淆的更新规则：

1. `previous_weights`在每次教师生成时前进；每个样本的参考前缀只有真实重算才前进。
2. 公共学生SGD后不能重置认证参考。下一次教师快照差必须涵盖上一轮公共更新以及本轮私有更新的净移动。未求分数的样本继续累计多个教师快照之间的保守预算。

按教师快照求差已覆盖两快照间最终净变化，不必记录每个SGD子步；对长期未重算样本，再对这些快照间预算求和。当前实现没有用更激进的抵消规则缩小这个累计上界。

## 5. 成本与有效范围

全量头部打分约为 $O(MKd)$；类对参数移动维护约 $O(K^2d)$，候选构造约 $O(MK)$，位集合边检查约 $O(|E|)$，另加未认证端点打分。因此不保证每轮都省时。K变大、图变密、模型移动变大时，维护成本和回退率都可能抵消节省。

当前`public_scaling/certification.py`的`_advance`直接创建`K×K×d`临时数组，**没有在当前公共核心中实现分块类对预算**。位集合采用uint64，限制 $1\le K\le64$；超过64需更换表示并另行验证。

浮点路径使用 `1e-10 * (1 + abs(bound) + abs(gaps))` 防护；有限测试零错误不是全输入IEEE浮点证明。极小间隔、极大尺度和前缀相减仍属于数值边界。整数测试路径使用L1特征半径和类对增量的无穷范数界，不与浮点L2公式混为一谈。

本证书依赖固定特征与线性头。解冻编码器、改变公共样本或图的身份后，不能直接沿用旧缓存。理论可为其他冻结骨干上的线性头提供接口，但当前实证主要是异宽MLP，未等同验证任意模型。

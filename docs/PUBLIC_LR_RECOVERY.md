# STL-10单簇与近单簇问题的处理记录

2026-11-06。研究目标为精确关系生成的计算开销优化，质量使用预定副作用护栏。近期已完成N12公共更新干预与公共学习率0.05初步确认。

## 问题与定位

公共2步、有效学习率0.1在部分高异构或较大K配置中出现持续集中。N12/K10/强非IID/seed1003最终平均最大簇占比96.24%，3/12客户端≥99%，严格单簇为0。N6/K64/强非IID/seed1002逐渐退化，最终6/6完全单簇。原B/E/D轨迹精确一致。

第一轮在N12已知失败种子、原缓存与私有更新下运行仅私有、公共1步、公共2步半学习率3条200轮B轨迹。最终平均最大簇占比为33.26%、34.96%、35.00%，均无≥99%客户端。两个公共干预到第40轮仍有短暂集中，第60轮及以后记录点恢复。仅私有分支也出现早期集中，说明初始化和私有启动过程仍需纳入解释。

保留两批公共边及顺序、只降低公共有效学习率亦能恢复，支持公共更新强度参与维持和放大持续集中的解释。具体反馈因果环节及其他因素的作用仍需按观测范围判断。

## 当前候选设置

保留公共每客户端每轮2步，将public_weight从1.0调整为0.5。既有学生更新使用head_lr×public_weight，因此公共有效学习率从0.1降至0.05；私有学习率仍为0.1。

随后在N12/K10与N6/K64两类场景中，覆盖健康种子、已知失败种子及新seed1101的IID/强非IID，共8个配置。16份配对记录包含11份新运行与5份历史复用。0.05全部通过预定最终结构、过程和NMI地板，适用的5个平均ACC下降≤1个百分点护栏也均通过。0.1参照为5/8通过。

|强非IID配置|平均最大簇占比，0.1→0.05|≥99%客户端，0.1→0.05|
|---|---|---|
|N12/K10/1003|96.24%→35.00%|3/12→0/12|
|N6/K64/1002|100%→30.68%|6/6→0/6|
|N6/K64/新1101|92.47%→43.35%|4/6→0/6|

五个原本结构与NMI合格的配置，平均ACC均略增，副作用护栏全部通过。逐客户端变化可有不同方向。新seed只有1101一个随机实例，两个划分分别报告。N12/1003的0.05结果来自前一轮干预，按历史复用记录说明。

## 应用范围及后续

0.05作为下一轮STL-10资源实验的候选，范围限于当前固定表示、两步训练和已测矩阵。早期短暂集中仍在部分配置存在。对新任务、不同预算或更低学习率的稳定性分别验证。

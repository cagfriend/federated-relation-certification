# 已完成实验设计记录：STL-10 公共2步下的B/E/D计算对照

日期：2026-11-01。状态：原设计建议记录；对应正式实验已完成。实际冻结协议为[stl10_compute/PREREGISTRATION.md](../experiments/stl10_compute/PREREGISTRATION.md)，实现按每20轮观察，未实施本建议中的0–10轮额外检查点。结果见[报告](../experiments/stl10_compute/results_full/report.md)及[审核](../outputs/stl10_compute_results_20261101/REVIEW.md)。后文保留原建议内容用于追溯。沿用长程验证预先规定的后续方向，不重新选预算。

## 要回答的问题

公共2步在既有长程验证中通过了预定护栏。本实验回答：在这一配置下，关系认证D能否保持与全量B、逐样本认证E完全相同的硬关系及训练轨迹，同时获得净计算省时？

主要比较D/B及D/E的完整头部训练耗时，生成阶段用于解释来源。质量只作护栏，不要求ACC提高。

## 公平性和锚点

复用6份原stl10_transfer缓存，正式运行前检查冻结环境、缓存文件与数据身份。不得重训AE或重抽公共图。种子1002/1003的新B运行与已完成2步长程B轨迹核对所有共有非计时逐轮字段、初始/最终头摘要及共同检查点指标；seed1001的初始头、图和私有工作量对齐原8步历史B。

**B也要重新运行。** 旧长程B记录用于轨迹锚点，不能拿旧时段的B耗时与新E/D耗时拼成主要性能比值。新三元组尽量连续运行。

B/E/D每轮都生成和聚合完整8192边；学生只消费固定随机顺序的前512边。三方法的学生边序列、目标、私有批次及训练次数必须完全相同。

## 记录与校验

- 精确性：独立全量教师oracle逐轮核对硬关系，E/D同时核对候选集合包含当前完整计算标签；三方法非计时字段、目标、头摘要、损失、通信和评估一致。任何错误立即报错并停止，不能将其作为质量容忍。
- 主计时：完整头部耗时含方法初始化；报告逐seed D/B、D/E比值、省时百分比和绝对省秒。每划分分别汇总3个配对seed的中位、范围和胜出数。
- 成本分解：私有更新、关系生成、协议处理、公共更新；认证维护、必要端点比例、候选数量等沿用已有可测字段，不只展示前向数量下降。
- 准备成本：C0、缓存加载与完整头口径分别记录。复用缓存不等于历史准备成本为零。新增校验/观察时间单列，oracle及额外评估在方法计时外。
- 资源：持久数组和真实编码通信字节。进程峰值含oracle与评估，只作描述，不代替隔离内存专测。串行总时间不称为实际并行轮时延。
- 质量：0/1/2/5/10及20/40/…/200检查点，逐客户端簇计数、最大簇占比、ACC/NMI/ARI；每轮教师正边比例。沿用longrun的S1/S2/Q1/Q2，早期事件保留，S2从20轮起判；seed1001不能预判通过。

若完整覆盖全部18条，预期关系oracle比较176,947,200次，E/D候选成员比较235,929,600次。计数与既有审计定义一致时才可作完整覆盖检查；不能把这些次数当作独立统计样本。

## 判读规则

先判精确性，再逐配置报告质量护栏，最后解释计算净收益。D/B省时而D/E不稳定或变慢，则说明相对全量有效、相对标签认证的额外收益不足；保留这一边界，不另挑seed或改预算。

本轮只有每方法一次，三个seed的结果用于描述跨训练实例稳定性；不能直接宣布已经排除机器计时噪声。只有发现值得确认的小幅收益时，后续才单独安排冻结配置的技术重复，不把重复次数或轮数伪作更多独立seed。

任何配置严重退化仍报告原计时和护栏失败；不得当作有用聚类任务上的成功迁移，也不事后删去该配置。如果只有部分配置通过，应按通过范围限定结论，不用总体中位数掩盖。

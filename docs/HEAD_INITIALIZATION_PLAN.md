# 下一实验：随机头与KMeans中心初始化对照

更新：2026-11-16。状态：用户已确定优先方向；本次仅更新计划，实验代码与正式运行尚未启动。

## 目的

检查当前原生头部偏簇是否能通过利用已有KMeans中心初始化缓解。比较完整初始化策略的影响，不能仅凭本实验归因为方向、偏置或置信度尺度中的某一个因素。当前方法的主要贡献仍为资源优化，ACC提升不是通过前提；同时逐客户端保留明显偏簇风险。

## 最小矩阵：4条200轮轨迹

|维度|设置|
|---|---|
|方法|仅当前Ours，随机初始化 / KMeans中心初始化|
|划分|IID、Dirichlet α=0.1|
|种子|1201，与外部对照同一实例|
|训练|200轮；每10轮评估，0轮额外观察|
|数据和模型|复用external_pilot缓存，私有总1200、公共512、测试1000，容量[100,200,300]×2，宽度[128,128,128,256,256,256]|
|保持一致|冻结编码器、私有固定伪标签、matching图、各随机流、私有/公共更新顺序与步数、学习率、聚合和差分编码|
|私有校正|仍仅客户端0和3，不在本实验扩展到全部客户端|
|公共权重|仍[0.125,0.5,0.5,0.125,0.5,0.5]，head_lr=0.1|

不重跑三个外部方法；其结果保留作为资源—质量背景。500轮、新seed确认、全部客户端私有校正均后移，避免本轮同时改变多个机制。

## 两个分支

- 随机组：完全复用既有随机头初始化规则。前200轮对照已完成observed结果的逐轮模型/头部摘要、非计时统计、通信、已有检查点评分；新增探针不影响训练随机流。
- KMeans中心组：复用生成固定伪标签的同一次KMeans拟合及其中心，不重新选择K或重新聚类。初始化 w_k=2c_k，b_k=-||c_k||²，整体正比例系数固定1，不事后按质量调温度。其argmax与最近欧氏中心一致；偏置必须保留。浮点近似平局另记，不以精确实数等价代替数值检查。
- 两组各自从自己的初始状态建立教师认证缓存；不能共享随机组的标签/间隔缓存。不同初始化引起后续教师目标和轨迹改变是干预结果，不要求两组轨迹相同。
- 正比例系数不改变初始硬分配，但会改变softmax和梯度；因此该对照验证“中心初始化整体策略”，不宣称单独隔离了几何方向。若后续确需拆分尺度影响，再单独设计尺度匹配对照。

## 观测

所有客户端均记录，不仅看0/3或总体均值。完整私有集、同一公共探针和固定测试集分别报告。

1. 初始化：伪标签频数、头权重/偏置范数、硬簇大小分布、最大簇占比、空簇、平均softmax分布、最大概率、预测熵、top1-top2 logit间隔及概率间隔。中心组对私有伪标签/最近中心的初始匹配率。
2. 每轮三时点：私有更新前、私有更新后（教师快照）、公共更新后。在私有集和公共探针记录上述硬/软分布、私有伪标签拟合率；记录实际教师同簇边比例和提交目标统计。探针只读，单列成本。
3. 测试：0、10、…、200轮逐客户端原生头部ACC/NMI/ARI、簇分布和置信度；原有KMeans后处理评分作为辅助单列，不替代原生结果。
4. 资源：初始化转换开销、特征提取、训练时间、通信及关系认证率；计入中心初始化成本。探针和oracle不混入方法计时。真实关系核对须零错误。

## 判读规则

- 初始硬分配恢复而概率仍接近均匀：只能说明修正argmax偏置，不能宣称形成高质量语义。
- 初始化恢复、私有步后再次集中：优先看固定伪标签分布和私有拟合。
- 私有步后健康、公共步后集中：支持公共更新参与放大，后续再设计目标可靠性干预。
- 全程及末轮逐客户端报告单簇、最大簇≥99%事件；即使未触发99%，98.2%等明显偏簇仍展示原值，不称“健康”。
- 将两个划分的初期事件数、最后50轮最大簇/空簇/熵、末轮原生质量和额外成本配对比较。单seed只作探索性结论；本轮不通过事后选最好检查点、追加温度或调整学习率挽救结论。
- 不预设“均匀10簇”是非IID客户端应有分布；分布均匀本身不是质量恢复证据。正式统计性质量非劣和防塌缩结论留给后续新seed确认。

# 论文写作计划：精确关系认证与计算优化

日期：2026-11-01。这是基于当前证据的写作路线，不是论文已经投稿、创新性排重完成或全部实验完成的声明。

## 1. 先定主张与题目

建议暂定题目：**异构联邦聚类中的精确关系认证与教师计算削减**。

论文中心句：在固定表示、线性聚类头和公共样本对图的设置下，关系有时可以在端点具体标签尚未确定时被确定；利用这一点，可以减少生成相同硬关系知识所需的教师前向计算，并研究其整体时间与内存代价。

研究对象是数据非IID、同模型家族宽度不同的客户端；不限定CNN。当前具体证据来自不同宽度MLP编码器的冻结特征和线性头。不要将当前认证直接推广到持续训练的完整非线性网络。

临时客户端承担聚合者是目标半分布式架构；真实训练仍为固定聚合者、全员在线的串行内存模拟。已有独立受限恢复实验，但尚未把临时选举、模型恢复和真实网络完整接入训练。若保留“半分布式”作为标题核心，须先补这部分系统证据；否则将其写为适用架构和未来部署方向，明确已验证的范围。

## 2. 三个贡献按强弱排序

1. **关系级认证机制。** 相对全量生成B及逐样本标签认证E，直接判断公共图边关系是否已经可确定；只对仍无法解决的边收集、去重必要端点并前向。比较对象、关系目标与训练轨迹相同。
2. **可重用缓存与完整成本核算。** 各样本以最后一次真实计算状态为参考，累计教师参数变化；变化包含前轮公共更新与本轮私有更新。把候选维护、端点收集、首轮初始化、回退计算全部计入时间，并报告内存代价。
3. **收益及适用边界的实证。** 在公共规模、图、更新幅度、私有头部负载、IID/非IID和不同宽度条件下，报告D相对B及E的净收益与失败边界；在第二数据集上先固定避免持续退化的预算，再测相同配置下的计算性能。

第2、3项是机制实现和验证贡献，不能替代与既有研究的区别。自适应完整/差分编码作为配套机制描述；除非补足相对已有通信方法的独立证据，不把“首次差分传关系”写为主要创新。不要把“首次公共样本蒸馏”“首次事件触发”或“提升聚类准确率”写入贡献列表。

## 3. 按这个顺序动笔

**第一步写问题定义和方法，而不是先包装引言。** 定义客户端、固定公共图、各自簇标签和硬关系、聚合计数与学生目标。说明簇编号不必对齐：边关系在每个客户端内部判定，再跨客户端聚合。当前共同K=10；位集实现范围与真实训练覆盖范围分开陈述。

方法部分建议包含以下六段：

- 基础训练：私有固定伪标签CE → 教师快照 → 完整公共图关系 → 等权聚合 → 当前学生头公共BCE。
- 全量B：每轮所有公共点完整前向。
- 标签认证E：必须确定每个相关端点的具体获胜簇才能解决其标签。
- 关系认证D：两候选集不相交即异簇；相同单元素集合即同簇；其余边只刷新必要的不确定端点。
- 缓存时序：只有真实前向才刷新对应样本的参考状态；连续跳过的累计漂移不能遗漏。
- 提交与编码：完整/差分/无变化按真实字节数自适应选择；B/E/D用相同协议，不把共有通信收益归到D独有贡献。

插入一个核心例子：端点候选分别为{1,2}和{3,4}。E尚不知道两端标签，D已知道二者异簇。这比单独展示更高认证率更能说明方法区别。也要给一个候选交叠的反例，说明D何时必须回退。

**第二步写正确性与复杂度。** 先给精确算术下的条件命题：如果各候选集合确实包含当前教师的获胜簇，那么上述两种关系判定以及必要端点回退可以还原完整图硬关系。证明按边分类即可。

必须另证候选集合的保守性：从实际代码采用的类对参数变化界、特征范数、分数间隔和累计参考状态推导，写明平局时的argmax规则。不能只证明集合操作，再把集合本身的正确性当作已证明。

浮点实现单独写：当前有保护项和压力测试，尚无覆盖全部IEEE舍入情形的形式证明。有限测试零错误可以报告，不能称为全输入的浮点精确性定理。后续数值边界专项可增强证据。

复杂度比较至少分解为：类对参数变化维护、每点候选维护、图边位集判定、未解决边端点收集和去重、剩余教师前向、缓存刷新。用M、边数、K和特征维度说明成本如何变化；不要只拿“少做了多少前向”代替总复杂度。

**第三步整理实验，再写引言和摘要。** 每条摘要数字都对应一张最终表和固定统计口径；未完成项目先留占位，不能把预计收益写进去。

## 4. 实验章节应回答的五个问题

|问题|主要对照|主要指标|当前状态|
|---|---|---|---|
|结果是否保持一致|同配置B/E/D|硬关系、聚合目标、参数摘要、逐客户端评估|已有多轮实验支持；新STL-10两步配置待复核|
|相对强基线是否省算|D/B及D/E|完整头耗时、绝对秒数、含准备成本口径；生成阶段作解释|Fashion-MNIST已有证据，收益与配置相关|
|哪些条件影响收益|更新幅度、M、degree、私有头部预算|候选大小、关系认证率、必要端点比例、维护时间、净省时|已有探索，K和客户端数等仍待扩展|
|资源代价是什么|同配置B/E/D|持久数组、隔离进程峰值、通信字节、准备/构图成本|已有部分证据，需保留内存增加的代价|
|能否迁移到有效轨迹|STL-10固定公共预算|预定退化护栏及同预算计算比较|1/2步200轮验证完成，2步B/E/D待做|

正确性证据与性能证据分开。新种子和技术重复的单位不同；先在seed内处理重复，再按seed配对。不能把200轮或数百万条边当作数百万个独立样本。插电补测的事后合并规则必须保留，不能重新写成原预注册固定两次重复均通过。

ACC/NMI/ARI是质量护栏和行为记录。相同配置下精确D应与B/E一致；不同训练预算允许预定范围内小幅质量变化。无需要求D提高ACC，但不能用严重单簇的结果证明有用任务上的迁移收益。

## 5. 本轮STL-10结果怎样写

可直接据结果写为：

> 为检验减少公共学生更新能否避免持续严重退化，我们固定其余训练设置，在两个未参与步数选择的种子和IID、Dirichlet α=0.1划分上，对公共1步和2步分别运行200轮，共8条B参考轨迹。所有轨迹均满足预先规定的结构与质量标准。按运行前规则选定2步，其最终平均ACC为19.39%–20.76%，24个客户端均非单簇，单客户端最大簇占比最高41.275%。seed1002的强非IID运行曾出现早期单客户端坍缩，但在第20轮及后续观测检查点均已恢复。

紧接着说明：这支持这些配置下的长程可用性，不等于普适防坍缩；原8步条件的严重退化保留为适用边界。两步相对八步的训练预算减少不计为认证算法收益。本轮没有E/D，不报告两步配置的认证加速结论。

## 7. 引言与相关工作的写法

引言按四段展开：异宽模型难直接聚合参数 → 公共关系知识允许不同表示协作但生成有成本 → 标签认证可能过度要求恢复具体标签，而学习目标只需要边关系 → 本文研究关系级认证及其净收益与适用边界。

相关工作按“模型异构蒸馏/公共知识”“聚类关系知识”“标签稳定性与事件触发/懒计算”“差分通信与半分布式协议”组织。逐篇指出其恢复对象、假设、节省的阶段和实际成本口径，再与本文对应。本文档没有进行新的文献检索；正式稿须再次核实最接近工作的原文及可比条件，当前不作“首次”或“尚无同类研究”的新声明。

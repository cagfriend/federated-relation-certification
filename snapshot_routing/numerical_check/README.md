# 关系认证的浮点边界核验

用小型冻结特征和线性头直接检验现有 E 逐样本认证、D 关系认证的硬关系。完整矩阵固定 13 个实例，约 1700 个教师快照。

| 输入族 | 设置 |
|---|---|
| 极小间隔 | 在 1 附近按 binary64 的浮点刻度构造平局及翻转，覆盖 K=2、10、64。 |
| 大数相消 | 两个类别包含相同的大项与反号项，只有一项小分差不同。使用 2^40、2^53、2^60 的量级，改变小项在点积中的位置和特征宽度。 |
| 累计前缀相减 | 先让偏置在大尺度上往返并返零，再施加连续小更新。保持原 E/D 缓存维护和回退，覆盖累计量级 2^40、2^54、2^60，最长 1024 次小更新。 |

B 运行现有 float64 全量关系生成。独立参考把每个输入值按 binary64 精确转成有理数，再逐项相乘与求和，两边都按最小簇编号处理平局。E/D 的探针观察回退前候选掩码、缓存分差、前缀及上次重算轮次，并记录实际回退的端点。

**主验收**为每个实例的 E 和 D 硬关系与 B 完全一致，且覆盖全部快照。另报 B 对有理数参考的标签及关系差异，以及 E/D 缺失 B 或有理数赢家的次数、局部回退与全量 B 标签不同的次数。不同证据分列，进程继续处理其余实例。该矩阵采用定向合成极端输入，报告列出具体覆盖的设置。

## 启动与输出

从项目工作区根目录运行：

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.numerical_check.run --preset full
```

输出默认在 `outputs/snapshot_routing_numerical_full`。用 `--preset smoke` 运行每族一个实例；用 `--case 实例名` 重跑指定例子，或者用 `--output` 另存一轮。已完成记录通过校验后可用 `--resume` 复用。

- `report.md` 和 `cases.csv` 汇总差异，`rounds.csv` 保存逐轮计数。
- `cases/实例.json` 记录每类首见差异、原分数、精确分数、候选和实际回退。
- `witnesses/实例.npz` 保存带差异实例的完整特征、图与权重偏置轨迹，可复查最早差异轮次和后续缓存变化。

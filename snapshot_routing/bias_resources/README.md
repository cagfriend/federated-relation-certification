# 偏置净变化 D 的资源对照

对照旧 D 与第一项数值实验的候选 D。复用 E42 的 18 条已封存 STL-10 快照，
每条含 200 轮。配置覆盖 M=512、4096、16384，IID 和 Dirichlet α=0.1，
以及种子 2021、2022、2023。每配置有三个配对，每对的两种方法分别运行在独立
单线程进程，前后顺序交替。完整矩阵共 108 个计时进程，不需要重训或下载。

## 记录口径

- 主耗时包含第一次全量打分和缓存初始化，以及其余各轮的认证和补算。
  载入、逐边验证、通信回放和分段探测都在主时间区间之外。
- 核对每轮每客户端的关系向量与 E42 当时封存的 B 输出，并核对重复间的关系摘要与
  非计时计数。初始全量前向也计入端点数。打分 MACs 按实际端点、特征维度及簇数
  逐客户端换算。
- 记录精确的持久缓存字节、已加载输入时的进程峰值和主回放后的进程峰值。
  峰值包括进程开销及核验，与纯认证缓存分列。
- 每配置首个配对另做一次带探针的诊断回放，测量参数推进、候选筛选、回退打分和
  其余生成环节。使用原自适应协议做内存回放，按轮记录含注册开销的累计上下行字节。
  零错边时复核全部轮的通信计数与封存的 B 完全一致。

## 采用标准

主场景为 M=4096，确认使用 2022 和 2023，2021 与其他规模单列。逐配置先取 3 个
配对耗时比的中位数，每种划分再取两个确认种子的中位数。每种划分的汇总比值须
≤1.00，每个确认配置的中位数须 ≤1.02。各配置须有 3 个可用的配对，新旧均对 B
零错边，打分 MACs 和持久缓存不增加，通信计数一致。若某配置的三个配对峰值工作集
均上升，则判为稳定增加，资源门槛未通过。峰值系统指标缺失则该门槛未核实。

同一配对如观测到供电状态切换或任一运行累计休眠至少 1 秒，原始时间照常汇报，
该配对的计时资格标为未通过。未知读数照实记录。资源通过与第一项合成数值验收
分别记录，资源结果不能消除已观察到的数值差异。

## 启动

从工作区根目录运行。完整 E42 快照默认位于此前的 confirmation 完整结果目录。
冒烟使用此前的 release smoke 结果中的两个 M=64 快照。

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.bias_resources.run --preset smoke
D:\anaconda\python.exe -B -m snapshot_routing.bias_resources.run --preset full
```

可用 `--trace-root` 指定封存快照位置，用 `--numerical-output` 指定第一项正式
结果目录，用 `--output` 指定新的输出目录。中断时以相同配置加 `--resume`，
已封存的配对保留，未完成的配对从头重做。

`report.md` 给出判定，`pairs.csv` 记录配对时间与内存，`cells.csv` 记录逐配置
汇总，`phases.csv` 记录诊断回放的逐轮阶段时间与字节数。原始数据位于 `runs/`，
配对收据位于 `pairs/`。

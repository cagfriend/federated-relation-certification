# 权重区间与相消防护的开销消融

200 轮完整头部对照显示合并版的额外开销集中在关系生成。这个实验在同一批教师快照上量化两项防护各自的成本以及合并后的额外成本，供选择后续优化方向。

| 方法 | 权重累计区间 | 相消尺度检测、全批回退和重建 |
| --- | --- | --- |
| D，当前版 | 关闭 | 关闭 |
| W，仅权重区间 | 开启 | 关闭 |
| S，仅相消防护 | 关闭 | 开启 |
| C，合并版 | 开启 | 开启 |

## 实验设置

- 冻结 E42 的 STL-10 M4096 快照，seed 2022/2023 各含 IID 与强非 IID（Dirichlet α=0.1），六客户端，各 200 轮。四种方法接收同一批权重、特征和图，每轮核对存档的全量 B 硬关系。
- 每组四个匹配块，块内四种方法依次在独立单线程进程运行。每方法在四个位置各出现一次，每个有向相邻方法组合各出现一次。总计 64 次主计时。只计关系生成，包含首轮初始化、逐轮候选认证和必要重打分。统计每块的 W−D、S−D、C−D 和交互项 C−W−S+D。主表按配置汇总绝对差与相对总耗时，CSV 记录每次差值和中位数。
- 四组各加一次四方法的独立插桩回放，共 16 次。阶段包括首轮初始化、类间累计、逐样本候选与位集合、尺度检测、局部重打分及缓存更新、全批回退及缓存重建、其他关系操作。阶段计时用于定位成本，主计时来自未插桩运行。
- 检查同一方法的关系摘要、分轮错边、重打分端点、持久缓存和回退次数在各重复及两种计时方式间一致。插电且休眠累计低于 1 秒的整块计入主表。检测到至少 1 秒休眠时按相同顺序补测整块一次。

若 W 的增量在四组中持续大于 S，且阶段差主要在候选计算，就优先优化逐样本区间计算。若 S 占主要成本，则优先检查每轮尺度检测。交互项较大时，需要同时检查两项开启后是否改变了认证覆盖和重打分数量。后续改动需再次通过 25 例浮点回归，并回到完整头部配对确认实际收益。

## 运行

在实验工作区根目录接通电源后执行：

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.guard_cost.run --preset full
```

默认读取 `outputs/snapshot_routing_confirmation_full`，结果写入 `outputs/snapshot_routing_guard_cost_full`。中断时加 `--resume`，已封存块继续保留。用 `--source` 指定移动后的 E42 结果目录，用 `--output` 指定新的空目录。短测 `--preset smoke` 使用一组真实轨迹的前 10 轮，跑一个主计时块和一个插桩块。

结果入口为 `report.md`。逐块四方法及交互项见 `blocks.csv`，逐次资源数据见 `runs.csv`，独立阶段数据见 `phases.csv` 和 `phase_deltas.csv`，首错位置和逐轮数据在 `runs/` 与 `profile/` 的 JSON。

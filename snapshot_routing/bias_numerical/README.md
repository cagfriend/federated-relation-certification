# 偏置净变化数值对照

旧 D 使用累计偏置移动上界，新 D 在同一缓存位置保存上次打分时的类间偏置差。本轮
用当前类间偏置差减掉缓存值，得到竞争簇相对原赢家的净偏置变化。新 D 复用原有
权重移动上界、候选筛选、边认证及回退打分。B 使用全批 float64 打分，另用有理数
计算作为区分 B 自身舍入误差的参考。

## 固定矩阵

完整矩阵复用 E47 的 13 个原例，并加入 8 个实例。

| 新增场景 | 固定配置 |
| --- | --- |
| 偏置累计 | 量级指数 55、58，分别有 48、192 次小更新 |
| 大共同偏置与近乎平局 | 公共偏置基准为 2 的 36、48 次方，竞争差按浮点间距变化 |
| 权重累计，偏置固定 | 量级指数 55、58，分别有 48、192 次小更新 |
| 大数相消与偏置累计叠加 | 点积量级指数 54、56，特征宽度 17、33，先施加指数 58 的偏置往返 |

通过要求包括全部轮次配对、以 B 为参照复现三个已知偏置累计反例且两个新增偏置
累计反例确实触发旧 D 的不一致、这些纯偏置累计实例的新 D 无错边，以及全矩阵中
没有新引入的错边。对同一轮、同一边编号，旧 D 错而新 D 对记为已修复，两者都错记
为残留，旧 D 对而新 D 错记为新引入。候选排除和回退标签分歧另外记录。权重累计及
大数相消的残留单列。

## 运行

从工作区根目录启动。冒烟矩阵含 7 个实例，用于核验流程。

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.bias_numerical.run --preset smoke
D:\anaconda\python.exe -B -m snapshot_routing.bias_numerical.run --preset full
```

默认输出到 `outputs/snapshot_routing_bias_numerical_smoke` 或
`outputs/snapshot_routing_bias_numerical_full`。重跑可用 `--output` 指定新的空目录。
`report.md` 和 `completed.json` 记录实际判定。命令成功结束表示产物写完，查阅
`passed` 获取实验是否通过。`cases.csv` 是实例汇总，`rounds.csv` 是逐轮原始计数。
`cases/` 与 `witnesses/` 保留首个异常轮的中间状态和完整输入。

本实验统计前向端点用于诊断。旧 D 与新 D 的实测耗时、内存和真实 STL-10 轨迹
回放属于第二项实验。

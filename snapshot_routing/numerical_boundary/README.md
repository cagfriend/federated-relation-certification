# E48 残余错边定位与修补筛查

完整头部实验已确认当前 D 在四个 M4096 配置相对 B 的收益。本实验验证已知数值反例的修补，并测量新增防护开销。

## 配置与判定

完整矩阵包含 E48 的 21 例，以及事先固定的四个补充实例：权重累计 (2^{56}) 与 74 个小更新，两种相消项布局（指数 55/57，宽度 19/41），以及 33 类近乎平局。短测包含 E48 两个权重累计、三个相消和一个近乎平局原例。

1. **定位。** 按原生成路径保存候选集合和实际刷新端点，检查 B 的赢家是否已被排除、实际局部打分结果是否与 B 不同。在同一轮原缓存上分别补入 B 赢家、将局部刷新换为同一全批 B 的切片，并同时施加两者。只在权重累计例使用有理数精确累加已计算的每轮权重移动量，确认丢失发生于累计与相减。干预仅作诊断。边级输出保留原 D、旧 D、B 和有理数结果，可追踪相同轮次和边编号。
2. **修补。** 从当前 D 出发做三组独立完整回放。权重组为已计算的移动量维护向外舍入的上下界，累计区间用当前上界减缓存下界。相消组用特征与头参数规模筛查可能的舍入风险，有风险时用与 B 相同形状的全批打分并刷新状态，脱离风险后再全批重建一次。合并组使用两项防护。相消筛查是经验门槛，权重区间覆盖已计算的移动量，整体验收是有限回归检查。
3. **验收。** E48 的输入摘要及错误计数必须复现。两个权重实例由权重组单独修复，三个相消实例由相消组单独修复。合并组在整个矩阵相对全批 float64 B 零错边。逐边比较当前 D 与各组，分别输出修复、残留和新增。另列 B 对有理数差异。
4. **开销。** 数值通过后，`--replay` 在 E42 的四个 M4096 STL-10 存档轨迹上比较当前 D 和合并组。每格四个同进程配对，两个运行顺序各两对，固定单线程。核对 B 硬关系，记录生成耗时、重打分端点、MACs、持久缓存及全批回退和重建次数。该回放用于筛查新增开销，为后续完整训练计时提供决策依据。

## 运行

在实验工作区根目录执行：

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.numerical_boundary.run --preset full --replay
```

默认结果目录为 `outputs/snapshot_routing_numerical_boundary_full`。结果目录已存在时用 `--output` 指定空目录。只审计合成输入可省略 `--replay`，流程短测用 `--preset smoke`。真实输入用 E42 默认本地结果，移动后通过 `--source` 传入。

查看 `report.md`、`cases.csv`、`rounds.csv` 与 `edges.csv`。真实回放完成后另有 `replay_pairs.csv` 和 `replay_rounds.csv`。正式数值矩阵及所请求回放的差分判定见 `completed.json` 的 `passed`，运行结束时生成。

# 当前 D 与合并版的 200 轮训练对照

同一训练引擎比较当前偏置净变化 D 和合并数值防护版 C。C 使用数值边界实验的权重累计区间和全批回退，训练时根据自己的教师关系继续更新。两种方法从同一个冻结编码器和初始头出发，使用相同的公共样本图、学习率、私有批次和公共批次。分别用各自实际训练出的头测 ACC，逐轮记录硬关系、头参数和通信差异。

## 配置

- STL-10，M4096，六客户端，IID 与强非 IID（Dirichlet α=0.1），seed 2022 和 2023，共四组。
- 每方法 200 轮，每组四个配对。每组各有两次 D 先跑和两次 C 先跑，共 32 个独立单线程进程。使用本地 E42 数据及 E43 模型快照。
- 每 10 轮和初始状态测逐客户端 ACC、NMI、ARI 和簇占用。第 200 轮 ACC 的主值在六个客户端间等权平均，报告合并版减当前 D 的百分点，另记录客户端最大变化。
- 主耗时为完整头部初始化加全部训练轮，包含关系生成、聚合提交及私有和公共更新。同步测整次子进程墙钟，包含启动、缓存加载、测试、审计和写盘。共同编码器预训练成本单独记录。时间主表沿用插电及休眠检查，保留所有原始配对。遇到至少 1 秒休眠时自动重试整对一次。
- 分配置读配对时间差与 ACC 差。技术重复用于观察计时稳定性。若 ACC 或硬关系出现差异，按客户端及轮次检查首次分歧和差值。若 ACC 一致且 C 明显增加训练耗时，再用已存快照定位区间维护和尺度检测各自的成本。

## 运行

在实验工作区根目录接通电源后执行：

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.guarded_training.run --preset full
```

默认写入 `outputs/snapshot_routing_guarded_training_full`。中断后加 `--resume`，继续未封存的配对。E42/E43 移动过时，分别通过 `--confirmation` 和 `--source` 指定。用 `--output` 可指定新的空目录。合成短测用 `--preset smoke`，真实数据 10 轮短测用 `--preset real-smoke`。

先看 `report.md` 和 `cells.csv`。原始配对与阶段时间在 `paired.csv`、`runs.csv`，逐轮和逐客户端证据在 `trajectory.csv`、`quality.csv` 和 `runs/`。完成标记为 `completed.json`。

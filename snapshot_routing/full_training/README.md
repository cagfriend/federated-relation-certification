# M=4096 完整头部训练确认

在已完成的新种子确认数据上运行原完整训练协议。三种方法 B 全量关系计算、E 逐样本认证和 D 关系认证，分别独立运行自己的 200 轮私有更新、教师关系生成、关系交换和公共更新。

## 冻结配置

- STL-10，种子 2021、2022、2023，各有 IID 和 Dirichlet α=0.1。每格 M=4096，共 2048 条匹配边。沿用已确认的六客户端异宽、中心初始化、全客户端频数校正、私有保护和每轮两步公共更新。
- 复用上一轮准备缓存与样本库。每格复现编码器筛选，并检查选中模型、初始头、训练样本摘要、图和公共样本 ID。
- 正式先跑 18 条独立审计轨迹。逐轮与上一轮 B 的教师参数、硬关系、训练后头参数、聚合目标及通信核对。学生边顺序由原随机流复算。每 10 轮评估原生头的 ACC、NMI、ARI 和簇大小。
- 审计通过后，每格做三组 B/E/D，组内连续串行、轮换顺序，共 54 次独立单线程进程。正式计时逐轮保存轨迹摘要，与通过的审计比对。

## 耗时与判定

主要耗时为模型头部初始化，包括固定特征计算和图、协议初始化，加上 200 轮实际训练的总耗时。关系生成阶段单列，包含该阶段的首次缓存构建。逐轮核对、评估、数据载入与诊断输出在计时区间外。共同准备口径把上一轮实测的 AE 训练和本轮复现的快照筛选加回完整头部耗时，供解释收益摊薄。

D 对 B、对 E 各自比较。每格平均完整头部至少省 3%，且三次配对至少赢两次，计为达标。完整矩阵中，两种划分各至少 2/3 种子达标才支持该对照的跨种子结论。按格保留绝对省秒、比例、B 的生成占比、逐阶段耗时、缓存、进程峰值及通信。

沿用插电与休眠采样判据。检测到至少 1 秒休眠时，最多自动补测该三元组一次。原始三元组与补测分开保留，主表只使用通过检查的有效块，原始全计统计另列。程序中断后，已封存整组继续保留，未完成的一组按原顺序重测。

## 启动

从实验工作区根目录执行。默认来源为 `outputs/snapshot_routing_confirmation_full`，输出为 `outputs/snapshot_routing_training_full`。在不同目录保存上一轮结果时用 `--source` 指定，输出可用 `--output` 设置。续跑加 `--resume`。短测命令用 `--preset smoke`，默认读取之前留存的确认短测。

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.full_training.run --preset full
```

`report.md` 给出逐格及跨种子判定，`comparisons.csv` 给出原始和有效统计，`paired_blocks.csv` 给出每块差值，`runs.csv` 和 `quality.csv` 保存各路径资源指标及质量检查点。

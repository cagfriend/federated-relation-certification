# STL-10 同场景配对与规模边界

## 冻结配置

- 复用 E42 的 2021、2022、2023 三个种子，在 IID、Dirichlet α=0.1 各比较 M512、M4096、M16384，共 18 格。独立确认使用预先固定的新种子 2024、2025、2026，在两种划分上只跑 M4096，共 6 格。初始化阻断记录原种子及客户端，保留在确认分母中。
- 每格固定六客户端异宽编码器、中心初始化、全客户端频数校正、私有保护和 200 轮。沿用 E42 的私有更新和每轮两步公共更新规则，边不足一个预算时按原规则截断。不同方法共享初始模型、固定匹配边图、学生随机顺序和优化设置。
- B 全量打分。E 与当前 D 共用权重累计、偏置净变化界和缓存刷新算术，E 以样本标签为单位认证，D 以边为单位认证。Demand 复用 E45 的显式请求、并集广播和按需计数路径。
- 每格四条审计和四个配对计时块。每种方法在四个位置各出现一次。共 96 条审计、384 次正式计时，不含初始化阻断、补测和准备参考数据。计时逐次独立单线程进程，完整头部含初始特征计算、头初始化与训练各轮，记录私有、协调、生成、交换和公共更新。预训练、快照准备、审计检查和数据载入在计时之外。

## 核查和判定

B/E/D 逐轮与全量 B 核对完整关系、计数、目标、学生边顺序、更新后头参数、通信和评估检查点。Demand 核对本轮请求并集上的边关系及计数，并与 B 核对学生实际消费的顺序、目标、损失、头参数和评估检查点。正式计时须重现审计轨迹及端点计数。按宽度记录各客户端教师打分端点与对应 MACs，各阶段墙钟与内存采用配置级数据。

主报各配置完整头部的配对省秒、比例和胜出次数。每格至少省 3% 且四块赢至少三块为达标。M4096 新种子的同一划分须三个种子计时齐全且至少两个达标，分别报告 D/B 和 D/E。Demand 的排序、生成及协调开销、上下行字节和持久缓存逐格报告。各尺寸列出完整头部均值最低的路径。

正式主表沿用合格块的插电与休眠规则。存在至少一秒休眠时以原顺序补测整个块一次。初测、补测与资格判定均保留。续跑校验输入、源码、环境和区块回执，未封存的块整块重跑。

## 运行

从工作区根目录执行，正式输入为本地 E42 结果和 STL-10 原始数据。

```powershell
D:\anaconda\python.exe -B -m snapshot_routing.paired_boundaries.run --preset full
```

默认结果在 `outputs/snapshot_routing_paired_boundaries_full`，中断可在原命令追加 `--resume`。可使用 `--confirmation`、`--data-dir` 和 `--output` 指定路径。

`--preset smoke` 从已有合成 E42 轨迹验证历史分支，`--preset fresh-smoke` 从头生成合成新种子轨迹。正式表为 `report.md`、`cells.csv`、`comparisons.csv`、`paired_blocks.csv` 和 `runs.csv`。逐客户端端点与按需范围分别见 `client_widths.csv` 和 `demand_scope.csv`。
